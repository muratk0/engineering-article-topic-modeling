# Welding data documentation

[TARİH: 01.09.2018 ISMR]

MODERN WELDING SYSTEMS acquire information about electrical current, voltage and wire feed rate, welding speed and welding time. This data can be used to optimise welding processes and avoid errors. A prerequisite for this is an advanced power source that has matched external system components, such as the TPS/i from Fronius. This digital device platform is designed for extensive, rapid and precise monitoring and analysis functions for manual and robot-assisted operations.
