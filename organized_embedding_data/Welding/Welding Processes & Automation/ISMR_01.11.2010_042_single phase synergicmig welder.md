# SINGLE PHASE SYNERGICMIG WELDER

[TARİH: 01.11.2010 ISMR]

GYS Ltd, the French welding equipment and battery charger manufacturer, has launched MONOGYS 185-2S, a SYNERGIC single phase 13A/230V, microprocessor controlled MIG/MAG welding machine with simple user setup.

The user simply selects the welding mode, wire thickness and metal type, then sets the current and they are ready to go. The microprocessor automatically sets the optimum wire speed.

This compact machine is rated 180A @ 25% duty cycle with an 18-28V OCV and is suitable for a business with multiple users or less experienced welders where consistent performance is otherwise hard to ensure. It is designed to weld mild steel, stainless steel and aluminium using solid wires ranging from 0.6 to 1mm diameter at speeds ranging between 1–15m per minute using a welding current between 25-180A. It comes supplied with a 4m long welding torch and earth clamp.
