# A brief overview of some changes in the AWS D1.1 code

Plenty of welders are aware of AWS D1.1, Structural Welding Code—Steel, but they might not know that changes are made to the code every five years. The debut of AWS D1.1/D1.1M:2025 last year brings some alterations to the code that welders should know about before a welding inspector has to remind them.

very five years, the American Welding Society introduces an update to its D1.1, Structural Welding Code—Steel. This is significant because D1.1 covers material and design, fabrication, inspection, qualification, and reporting and recordkeeping as it pertains to structural steel fabrication and erection. It’s also noteworthy because not everyone gets updated on code changes right away.

It’s not that structural steel fabricators are ignoring the code; they are busy making sure that fabrication work is being done according to code specifications so that the beams and other structural elements pass inspection. But the copy of the D1.1 code they’re referencing might not be the latest version. Unfortunately, if they don’t keep up with the latest revisions, they could learn about their oversight during a visit from an AWS inspector—with negative consequences.

AWS D1.1/D1.1M:2025 made its debut last year. The Fabricator is sharing some of the changes that might be of interest to structural steel and heavy-duty fabrication shops. For a more complete summary of changes, check out "What’s New in AWS D1.1 2025, Structural Welding Code—Steel" in the May 2025 issue of The Welding Journal. WELDING PROCEDURES AND NEW MATERIALS

The AWS D1.1 code is unique out of all the codes [like D8.8, Automotive Arc Welding (Steel); D9.1, Sheet Metal Welding; D10.12, Pipe Welding (Mild Steel); or D14.3, Earthmoving & Agricultural Equipment Welding] in that it is one of the few that has prequalified welding procedure specifications (WPSs). Metal fabricators can feel confident that the welding procedures prescribed in D1.1 will work without the welds needing to be tested.

The code also provides industry a means to qualify welding procedures without having to pay for independent testing. An organization that wants to qualify a procedure involving a lot of variables could end up spending a lot of money to arrange the qualification tests. A WPS recognized in the D1.1 code does not require requalification.

With that in mind, there have been some changes in Clause 5, "Prequalification of WPSs," which summarizes prequalified WPS requirements for shielded metal, submerged, and gas metal/flux-cored arc welding. Table 5.1 is now organized by process to help with readability, and several electrode requirements have changed to be more conservative. Additionally, minimum current requirements were added for nonshort-circuit and pulsed welding processes, and maximum layer width requirements have been added.

In Table 5.6, where approved base metals for prequalified WPSs are collected, ASTM Grade 80 metal has been added to the new Group V.

In Table 5.11, new prequalified minimum preheat and interpass temperatures are included. The table now includes cast steels (such as ASTM 216) in Categories A and B. Also, ASTM A913 Grades 70 and 80 are included in new Categories F and G, respectively.

Tom Schlafly, senior engineer for the American Institute of Steel Construction and a member of the AWS D1.1 committee, said that having an ASTM standard listed in the table of materials that can be used in prequalified procedures is a great advantage for fabricators. Because these material developers routinely improve their products and have ASTM document those improvements, they also conduct weld tests during the new material’s development. The results are presented to the AWS task group on materials, and it approves proposals it believes are an improvement to the code.

WELD QUALIFICATIONS

Clauses 6.11 to 6.14, covering qualification information and testing requirements for complete and partial joint penetration groove welds, fillet welds, and plug and slot welds, have been updated to include clarifications from the previous code. Also, Table 6.5 and Figure 6.17 are new and relate to plug and slot weld qualification.

Clause 6.17.5, "Extent of Qualification," provides some clarity to personnel qualifications based on the type of weld qualified. For instance, if a welder is qualified using a complete joint penetration groove weld, that same person also is qualified to weld partial joint penetration groove, fillet, plug and slot, and tack welds.

PREHEATING CHANGES

Clarifications that took place in Clause 7 related to fabrication are examples of the D1.1 committee responding to industry input.

In Clause 7.6.2, "Extent of Preheat and Interpass," the required preheat and interpass temperatures were changed. The original code called for the temperatures to extend the maximum base metal thickness in all directions from the joint, but no less than 3 in. The new code reduces the required preheat and interpass distances for thinner materials:

• For base metal less than 1½ in. (38 mm) thick, the distance heated shall be at least twice the base metal thickness.

• For base metal 1½ in. (38 mm) thick and greater, the distance heated shall be at least equal to the base metal thickness, but not less than 3 in. (75 mm).

• For base metals of different thicknesses, the distances shall be based on the individual thickness of each base metal being joined.

Schlafly said that the D1.1 committee learned since the publishing of the 2020 update that some preheating specifications in the code may have been a bit excessive. Given the expense associated with preheating activities, the changes in the 2025 code can help fabricators involved in this activity.

GETTING INVOLVED

The D1.1 code is an ever-changing reference. Although changes are not as frequent as they were when the code was updated every two years, conversations about new materials, new technology, and industry trends are constant.

A good example is the removal of references to AWS A5.36/A5.36M, Specification for Carbon and Low-Alloy Steel Flux Cored Electrodes for Flux Cored Arc Welding and Metal Cored Electrodes for Gas Metal Arc Welding in the 2025 edition of the code. A5.36 was created by combining filler metal standards from an older D1.1 code to make them more compatible with European filler metal standards. Schlafly said that feedback from U.S. industry suggested that A5.36 wasn’t being accepted, so the decision was made to revert back to the original standards.
