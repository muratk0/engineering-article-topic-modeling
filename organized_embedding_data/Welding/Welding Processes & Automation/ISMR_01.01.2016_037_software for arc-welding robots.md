# Software for arc-welding robots

[TARİH: 01.01.2016 ISMR]

USING OFFLINE PROGRAMMING for arc welding robots, instead of ‘programming by teaching’, is becoming more and more common for manufacturers, even for small companies that can easily measure the benefits of such a software solution. The flexibility provided by offline programming is particularly relevant when the products to manufacture are varied, modular or subject to frequent changes.

Alma's almaCAM Weld is now a recognised software solution for robot offline programming. Dedicated to the offline programming of arc-welding robots and much faster than programming by teaching, almaCAM Weld enables a better utilisation rate of robots resulting in increased flexibility and improved productivity.

“Offering a user-friendly GUI, almaCAM Weld allows the user to program a robot from a virtual scene and qualified welding conditions. The parts or assemblies to weld, together with the tooling, are imported from a 3D-CAD system via native or neutral formats (STEP and IGES). A specific simulator takes all the controller parameters into account and enables the simulation of the movements of the robot on the screen,” said the manufacturer.

The software also provides automatic search for collision-free trajectories and realistic simulation with the complete cell. In addition, it also includes various productivity tools, such as the automatic transfer of welding programs, which helps to reduce programming cycle for similar parts. A post-processor, specifically adapted to the controller, generates in robot language the programmes prepared with almaCAM Weld. It can also manage the multi-controller functions of the new models of robots i.e. two robots and one manipulator that are synchronised. See www.almacam.com ■

## 2D laser cutting

AT THE 2015 Blechexpo exhibition in Stuttgart recently, TRUMPF introduced new laser cutting innovations. Among these was its intelligent beam monitoring system, Smart Beam Control, for solid-state laser machines in the TruLaser Series 5000. Smart Beam Control automatically regulates the laser’s focal position during the cutting process. This function also makes it possible to carry out a diagnosis of the cutting system from a remote location, using Teleservice.

“The new Condition Guide function for the TruLaser Series 5000 enhances transparency. A single glance is enough to determine the machine’s status. A traffic light system provides information on the condition of key elements that affect the machine’s cutting capacity. It can also, if desired, provide information on corrective actions to be taken by the operator. Line charts show the history of the particular condition and simplify forecasting the need for intervention.

Consequently, maintenance work can be planned efficiently and in harmony with actual needs,” explained TRUMPF.

TRUMPF also showed the TruLaser 5030 fiber at Blechexpo in Stuttgart with new laser power. In addition to the three-, five- and eight-kilowatt power levels offered in the past, the machine is now also available with the six-kilowatt TruDisk 6001 laser. This enables rapid processing, especially for medium and heavy sheet metal gauges. See www.trumpf.com ■
