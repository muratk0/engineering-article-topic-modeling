# Rotating Table Height Adjustable

[TARİH: 01.04.2024 The Fabricator]

Lifting Tables & Rotating Tables

The Siegmund rotating weld table with adjustable height provides easy handling with a flexible working position for heavy loads.

The Siegmund height adjustable rotating table provides an ergonomic and space saving solution. The work top height is infinitely variable and can be fixed in position by a side locking lever.

The height adjustable rotating table allows easy access around all sides of the workpiece. For quick and easygrounding without twisting the cable, we recommend our magnetic ground connection.
