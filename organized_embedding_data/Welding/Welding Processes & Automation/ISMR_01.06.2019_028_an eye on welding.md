# An eye on welding

[TARİH: 01.06.2019 ISMR]

KEMPPI'S UNIVERSAL WELDING management software, WeldEye, is now available for managing the quality of robotic welding. By collecting data from the welding robot and synchronising it with weld lists in the cloud service, WeldEye monitors robotic welding quality and its compliance with welding procedure specifications (WPS). In addition, the software aims to ensure full traceability down to each weld and welded end product.

Data collection requires that the welding power source is connected to WeldEye's Digital Connectivity Module. The device then transfers the data wirelessly to the software, where the information can be viewed and analysed further. In addition to the web browser-based user interface, the WeldEye mobile application can be used (for example) for real-time monitoring of welding parameters, operator identification or selecting the filler wire material.

"With WeldEye, you will know what has been welded, at which welding station and when. It also reports the used welding parameters, heat input and any possible deviations in real-time. The logic is based upon identifiers, which even helps us track a specific filler batch in welding production if it has been faulty," explained Vesa Tiilikka, Product Manager, Software at Kemppi Oy.

Development of the WeldEye software has been successfully piloted with Kemppi's robotic welding system, A7 MIG Welder. WeldEye's quality control functionalities are available when using WeldEye for welding quality management, which includes software modules on welding procedures, personnel and qualifications as well as quality management.

"All set-ups will be configured case-by-case, according to the customer's needs. If you have been looking for a robotic welding solution that can be monitored in terms of welding quality and traceability, I encourage you to contact us to see what we can do to help out," added Artturi Salmela, Product Manager, Automation at Kemppi Oy.
