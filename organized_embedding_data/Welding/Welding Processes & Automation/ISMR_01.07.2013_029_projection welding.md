# Projection welding

[TARİH: 01.08.2013 ISMR]

Cemsa SpA recently launched the MT CE 4T TVR, a new special projection welding machine series. The machine is designed for the production of components for the automotive market sector, in particular for car or other transport safety components.

“The system is designed to ensure automatic projection welding of four nuts in four different positions on sheets/plates with different geometries,” said Cemsa. “Normally, these plates are 2-3mm thick with nuts ranging from M8 to M12. To make the welding process easier, special nuts with tips are used to concentrate the current and therefore limit the warming effect. An alternative is to use nuts with collars, if hydraulic tightness is required.”

The welding process features four special heads, each dedicated to the welding of a single nut for precision and speed. The machine is equipped with a Medium Frequency system for more precise welding control and more consistent energy saving. To speed up the production run, the machine is equipped with a rotating table handling system with three stations: the first for loading the components; the second for welding using the four heads and the third for automatic unloading.

“The flexibility of this machine enables the integration and interface of the loading section with the latest generation of automatic feeding systems,” concluded Cemsa.
