# Portable electrode welding

[TARİH: 01.01.2017 ISMR]

EWM AG HAS brought one of the lightest portable electrode welding machines to the market. The Pico 160 cel puls, weighing 4.7kg, can be used for vertical-down CEL welding and TIG pulse welding for the 230-V lighting main. It has a new ergonomic design, with a focus on user-friendly operation.

"The new control's easy-to-read display enables welding parameters to be set precisely. This is an important prerequisite for simple reproducibility to ensure that consistent, high-quality welding results are achieved. Our single-hand operation concept also enables the functions to be set using a single large button, which means users do not need to remove their gloves every time they need to change a setting. Other advantages in day-to-day usage are the remote control connection option and the large connection sockets (50 mm²) which enable the machine to be combined with standard electrode holders and standard TIG welding torches with rotary gas valves," explained EWM.

Characteristics, hot start and an anti-stick function for sticking electrodes are all integrated as standard. The new pulse function also enables easy vertical-up and vertical-down welding without having to resort to the complex 'Christmas tree' technique, the manufacturer told SMR. This makes work much easier, especially in hard-to-reach areas or locations with poor visibility.

"The machine's switchable standby power-saving function and high mains voltage tolerances of -40% to +15% ensure smooth operation with generators and enable welding with mains connection leads of up to 100m in length. The machine is also protected against inadvertent connection to 400-V mains voltage. This makes the Pico 160 cel puls the ideal machine for use in industry and in workshops, for fast repairs and continuous operation," concluded EWM.
