# GoFa cobot welding package

[TARİH: 01.05.2024 ISMR]

ABB's GoFa collaborative robots are designed for performance, safety and collaboration.

"By helping to simplify the use of collaborative robots in welding applications, GoFa presents an exciting solution to the growing shortage of skilled industrial welders that is challenging many manufacturing companies. Our new GoFa arc welding package promises to revolutionise welding processes. The Cobot Arc Welding Package is a breakthrough solution that dramatically simplifies creating and executing welding sequences. The main innovation is the Easy Teach Device which uses lead-through programming and interactive buttons to determine weld points," Paul Garner, Account Manager Collaborative Robots, ABB, told ISMR.

With a growing worldwide shortage of experienced welders, companies need easy-to-use automation solutions to stay ahead of the game. The Cobot Arc Welding package has been developed to reduce the complexity of robotic welding and lower the barriers to automation for SMEs and first-time users (like manual welders).

"Fitted on our award-winning GoFa Cobot, the Cobot Arc Welding Package is the first of its kind to enable users to program a robot without using a teach pendant. Using the Easy Teach Device, users can automatically generate the programming code by simply guiding the robot's arm along the welding path. With the ability to cut down programming time by about 70 per cent, the Cobot Arc Welding Package is a gamechanger for the global welding market," outlined Paul Garner.

## Operational benefits

With the Easy Teach Device, users no longer need hours of training to use the device, making it suitable for high-mix, low-volume tasks. Welding sequences are automatically generated on the teach pendant, so that users can create and execute welding sequences in less than 30 seconds, cutting typical overall programming time by 70 per cent according to ABB.

"With GoFa's positional accuracy and superior lead-through programming, users are assured of high-quality welding, every time. All major operations are achieved with the easy-to-use device on the robot arm, making it simple and intuitive to use," explained Paul Garner.

All major components (including the robot, gripper, software, service etc.) can be bought from ABB, making it easy for anyone to buy and set up the device.

"The improvements delivered by the Cobot Arc Welding Package can help businesses to increase productivity, overcome labour shortages and operate more efficiently by automating welding processes. Using the package to assist with welding tasks can help augment worker performance and enable existing workforces to be deployed more efficiently, for example by carrying out additional welding tasks on other products. By seamlessly integrating into existing workflows and promoting efficient collaboration, the package has the potential to drive productivity and efficiency in welding applications to new heights," concluded Garner.
