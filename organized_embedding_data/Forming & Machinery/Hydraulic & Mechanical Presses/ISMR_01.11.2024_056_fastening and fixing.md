# Fastening and fixing

[TARİH: 01.11.2024 ISMR]

Controlriv GEN3 is a new process control system, developed by Rivit “to guarantee excellence and verify fastener quality". This system complements previous versions with new and enhanced features. It was launched at the EuroBLECH sheet metal exhibition in Hanover this October, where Rivit also presented several new fastening products.

“The industrial electronic device, made in Italy, verifies in real-time the correct fastening system and is designed for industrial sectors such as automotive, heavy carpentry, industrial automation, various assemblies and handling systems. Offered as a single model, Controlriv GEN3 allows a user to verify the correct fastening of the rivet-rivet nutslockbolt, through control of each Rivit tool to which it is connected. In this way, any errors can be promptly reported, saving time and cost. The new Controlriv GEN3 can be used in two modes: stand-alone or in a cluster (a network of interconnected devices), highlighted the Italian fastening specialist.

The compact and robust system physically separates its pneumatic and electronic parts, for quick and easy installation and maintenance. It provides real-time measurement of the compressed air pressure supplied to the tool, with programmable tolerance range and error signalling in case it is out-of-range. It also offers real-time monitoring of the fixing process with an alert system via notifications and colour coding.

Other features include data collection and storage, as well as configurability from remote control. Interfacing to Controlriv GEN3 can be done via Ethernet/Profinet or WiFi/Bluetooth. The new control system includes a practical front panel with a graphic display, one illuminated on/off button, six buttons for the main functions and one USB port. On the back of the machine, there is a panel with one USB port, compressed air input/output and four opto-isolated inputs/ three outputs and power supply, all of which can be connected via terminal blocks.

Rivit S.r.I. is based at Ozzano dell’Emilia, Italy, and supplies industrial, retail and construction sectors with products and consultancy on fastening systems and tools for the assembly and machining of sheetmetal. It is present in over 65 countries. The company, whose core business is fasteners and tools, became part of the FERVI Group in 2021.■
