## Modular tooling system

STEINEL's Module Tooling System (MTS), for progressive press tooling, combines the advantages of a standardised tool with the necessary flexibility for parts production. It features a standardised basic design and individual tool modules which are interchangeable, designed so that production remains flexible and retrofitting is designed to be quick and cost-effective.

The basic structure of the module system consists of a lower and head plate connected by guide pillars. It incorporates all the spring systems needed to generate blank holder forces as well as a sensor system for double-strip monitoring. It need only be installed once in a press and can then be fitted with different tool modules, according to production requirements.

Both the basic structure and the standardised modules can be increased in size incrementally, and adjusted as needed.

"As we use a high number of stocked standard parts and standardised semi-finished products, we can customise both the basic structure and modules to meet customer requirements and supply them in a very short space of time. If the basic structure is already installed in a press, it only takes a few minutes to fit it with different tool modules. Once you have invested in the basic structure and first modules, you can achieve significant design and toolmaking savings for all progressive tools. Further savings are achieved using standards and improved machine utilisation, due to rapid retrofitting between product series. In addition, the pre-installed basic structure minimises setup errors and increases process reliability," explained Pape.

"The biggest issue for customers is delivery times and the time it takes to manufacture a tool. The idea we have is to use a standardised tooling system where the upper plate creates the force needed and customers do not have to manufacture fresh tooling each time. All a customer needs to do is invest in the pre-loaded springs, not in an entirely new tool. It is very easy to manage, everything is standardised and little time is needed to change the module or the tooling (just 20 minutes, as opposed to four hours for a non-standardised tool) so it drastically reduces press downtime," added Pape.

Two STEINEL customers started using the MTS system three years ago. After extensive feedback and testing with them, STEINEL has now decided to launch this product into the market. Pape points out that the MTS 'is particularly interesting for customers who run smaller batch sizes, as it can save so much time, is completely interchangeable and can bring great productivity benefits'.

"Customers do not have to wait for tools or dies to be built and delivered. The standardised module can be used for any tool and tool-shops can save so much time with it. Users can also produce a variant of a part (some parts can have small differences) using the MTS. You do not need to change the complete tool, you just change the station. This is the next step for the tooling industry, closing the circle to meet toolmakers' requirements. There is no wasted time on delivering tools, either. Time is of the essence in toolmaking…."

## Nitrogain systems and manifold plates

STEINEL also introduced its Nitrogain nitrogen spring systems at Blechexpo, designed to connect the springs inside a tool, via a control system, so that users can see what is happening inside the tool.

"The standard today is to use a standalone gas spring. Nitrogen inside the cylinder increases force by 60%. When using more gas springs inside one tool, if they are not connected but stand-alone, a user cannot tell if, for example, one spring is broken which then creates a problem, and probably damage, in the tool. This can be extremely expensive. We decided to connect these three springs via a control panel with our Nitrogain spring so that users can see what is happening inside the whole system. An electronic device measures the pressure and stops the press if there is an issue – an important step to save the tool. This checks the entire process," explained Christian Pape.

"The next step is to use the manifold plate (with not as many contact points). When you are using more forming tools (i.e. two, three or four), then you may find that your press is not parallel to the upper plate – there may be small differences – so that your parts on the left side are not good, but the parts on the right side are OK. If you put a manifold plate on the upper part of the press, for a 3mm stroke from the cylinder, this will guarantee even force on both sides."

This process is successful in hot forming processes as metal sheets emerge from the oven at over 900 degrees and go straight into the tool. Water is then inserted to harden the sheet. The manifold plate ensures that the left and right tool force is even, which saves a lot of preparation time.

"Investment is high but turnover is rapid, as is Return on Investment. We are trying to bring this process into the progressive tool industry to use with smaller manifold plates which deliver more strokes per minute (3/4 strokes per minute) and we can see that this technology could be relevant for other parts of the industry, but with faster times (i.e. 300 strokes/minute)," explained Pape.
