# Rolling tube forming

[TARİH: 01.06.2015 ISMR]

THE DEMANDS FOR tube processing are increasing. Geometry is becoming increasingly complex and materials are becoming ever stronger in connection with progressively light design. At the same time, there are louder calls for efficiency across all sectors. Rolling tube forming by Transfluid offers a solution – a process that opens up special opportunities for forming and reduces the use of tools to a minimum. Rolling technology displays its particular strengths most clearly if forming is to be carried out on tubes that have already been axially pre-formed, if sharp-edged contours need to be created for sealing elements or if perfect surfaces are required.

“For tool-independent tube forming and for the creation of almost freely formed geometries, all T-form bead rolling machines have a servoelectric drive and CNC control system if required. As all setting parameters are stored there are no complex adjustments. The forming process is possible both from outside to inside and from inside to outside. Completely different geometries can be formed with a single tool, a clamping jaw and the rolling head. Tool wear is almost totally ruled out in a rolling process. The lubricants that are necessary in the forming process can also be reduced to a minimum,” said Transfluid.

If very demanding forming is necessary on high strength materials, then a closed rolling head is used. If complex geometries need to be formed almost without clamping length, then a roller head takes over this role, enabling the rolling or separating process across two rollers. If rolling tube forming reaches its limits for specific forming processes, then it is also possible to use pre-compressed tubes in the rolling process – or the rolling machine can be combined directly with a compressing machine.
