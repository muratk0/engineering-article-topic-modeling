# Five-module strip descaling machine

[TARİH: 01.04.2017 ISMR]

THE WHEELABRATOR TECHNOLOGY Centre (TC) in Zürich is set to deliver its first ever five-module HB strip descaling machine for a customer in Taiwan. Connecting the five blast chambers, with their four U105x500 blast wheels each, in series was necessary to accommodate the required blast power within a shorter-than-usual space in a new end-to-end processing line for the customer. The new HB machine is 28.5m long and is scheduled for commissioning in April 2017.

"The combined blast power of 2200kW from 20 blast wheels ensures efficient descaling at high throughfeed speeds of up to 151m/min. The TC has previously designed HB machine arrangements with up to six modules, but this was achieved by linking separate two-to-three module machines, which takes up considerably more space," said the company.

Machines in the HB range can be installed with or without foundation pit and can process steel strip of 600 – 2100mm width. The staggered positioning of each set of blast wheels helps the machines to achieve strong strip surface finishes.
