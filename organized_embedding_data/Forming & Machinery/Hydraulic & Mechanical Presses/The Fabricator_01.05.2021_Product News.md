Search function added to quoting software for improved speed, accuracy

Paperless Parts has added Paperless Search to its quoting software. This feature helps estimators prepare more accurate and consistent quotes by finding and referencing data from historical quotes and past jobs.

This feature puts data into a single, searchable, secure database in a digital format, allowing users to search by every word in an account, including information such as comments in collaborative chat tools, part names and quality certifications on prints from past jobs, and file names. Users can search for exact words or portions of words.

The software connects critical tolerances from technical drawings to quote items, from supporting file names to jobs won, and from chat conversations to specific parts. Results are ranked for relevancy using a scoring algorithm. As a result, users can type plain-English terms into the search box to find technical information or other details buried in the data of past quotes and jobs.

www.paperlessparts.com

Phased-array scanner provides wide coverage area

The new RollerFORM XL scanner from Olympus is a widecoverage tool for the inspection of composite components with large surface areas. Its tire with integrated phasedarray probe provides wide beam coverage to help increase the probability of detection and improve data accuracy.

The scanner’s tire also allows the system to obtain strong, reliable signals without a couplant pumping system. The tire is filled with liquid, and the material has an acoustic impedance that closely matches water, so interface reflections are minimized.

The optional low-frequency, large-elevation phased-array probe helps optimize beam penetration in attenuative composite materials. Inspectors can integrate this new wider model into existing wheel probe procedures.

Die protection features added to press automation controller

Wintriss Controls Group has added new die protection features to the latest version of its SmartPac Pro press automation controller. The Advanced DiProPac offers more than 10 new capabilities.

The additions include a customizable green sensor type called Green Flex that allows for specification of the required state of the sensor at the start and end of the ready window. The sensor can be set to require a specific number of actuations inside the ready window.

A new masking feature available on most green sensor types, including Green Flex, is used to monitor events that occur regularly but not on every stroke. Applications can include gagging, zigzag feeds, and those that require multiple cycles to produce part feature events that need monitoring on only some cycles.

To eliminate nuisance stops caused by the material "jumping" when the die opens, a bypass window can be programmed for static sensors. During the bypass, the sensor will be ignored, so any nuisance fault during that window will not stop the press.

Capacitive discharge welder features dual-pulse output

Amada Weld Tech Inc. has released the CDA1000A, a 1,000-Ws capacitive discharge welder for battery tab welding, honeycomb tacking, and welding of conductive terminals.

The unit is automation-ready and features dual-pulse output with control and monitoring of both pulses. The dual-pulse function helps overcome surface inconsistencies such as dirt and oil contamination during the first pulse and makes consistent welds with the second.

A built-in process monitor measures peak current for both pulses and displays the value after each weld. Upper and lower limits can be set for both pulses to help ensure weld consistency. An option to inhibit Pulse 2 if Pulse 1 is out of limits prevents weld blowout.
