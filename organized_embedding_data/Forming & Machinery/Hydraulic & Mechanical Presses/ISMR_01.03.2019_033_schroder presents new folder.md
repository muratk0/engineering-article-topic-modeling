# Schröder presents new folder

[TARİH: 01.03.2019 ISMR]

HANS SCHRÖDER MASCHINENBAU GmbH has introduced a new motorised folder, the MAKU. This machine is available in working lengths of 2520mm and 3220mm and is an entry into motorised thin sheet metal material of up to 1.5mm thickness.

"For tinsmith and repair shops, the MAKU is an extremely versatile machine – the letter 'U' in the name stands for 'Universal'. It replaces the well-established Schröder MAKV in this field of application. However, this machine has been developed completely independently using the latest technology. No other machine on the market offers as much clearance," explained the company.

"MAKU features a robust and torsion-resistant machine body, rapid and precise drives and intelligent software. In its standard configuration with standard tooling, it is a very versatile machine. The optionally available clamping beam tools, tinsmith blade, radius blade and various goat foot tools make it even more flexible. In addition to unprecedented clearances at the clamping and the bottom beam, for the first time there is now a folding beam available that is shifted back and holds a cranked folding blade, creating even further clearance. Until now, this geometry only existed on long folding machines."

The MAKU is equipped with the software control, nano Touch. Optionally available is industrial software control, POS 2000 Professional. See www.schroedergroup.eu/en
