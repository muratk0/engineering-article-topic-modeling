# Standardised modular

[TARİH: 01.01.2019 ISMR]

WITH ITS NEW LEANTOOL progressive system, Otto Bihler Maschinenfabrik has extended its standardised modular LEANTOOL tool kit with a linear version.

"This enables more efficient and costeffective production of lean progressive tools, and progressive components can be manufactured economically," it told ISMR. "With the standardised modular tool kit, radially arranged new tools for servo stamping and forming machines can be produced more easily, quickly and cost-effectively in a uniform process for the first time. With the LEANTOOL progressive system, we have now extended this successful concept to linear tool solutions."

"The LEANTOOL progressive system is the logical further development of the end-to-end modular system," added Marc Walter, Technical Sales, Bihler. "It opens up new possibilities for the production of more complex progressive components that can no longer be produced with the radial LEANTOOL.

"This enables manufacturing of stamped and formed parts and wire bending parts with up to eight bending operations. With the new LEANTOOL progressive system, more complex progressive components with twenty or more processing steps can be produced."

The new modular LEANTOOL progressive kit includes precisely defined modules and units for toolmaking. In addition to the tool carrier plate, this includes the tool module consisting of blanks, plate structure and smaller functional parts such as spring assemblies, fastening elements, claws and material guides. Also included are standard parts for various punches and units. Up to three tool modules with standard lengths of 250mm each can be mounted side-byside on the GRM-NC servo stamping and forming machine. Together with the cutting tool in the 400kN servo press, a total tool length of 1,420mm is possible. All these kit components form the basis for the actual toolmaking process, which begins with the planning stage including a simple and quick feasibility statement. This is followed by a simple and clearly structured design stage with the bNX software.

"The LEANTOOL progressive system features a small number of tool components and a particularly high degree of standardisation. Up to 70 per cent of the required components consist of standard parts. The actual number of functional units depends upon the project. Generally, the LEANTOOL progressive system consists of 100 tool parts plus around 50 cutting tool parts. On average, manufacturing costs can be reduced by up to 50 per cent compared to conventional tool solutions," added the manufacturer.

"It offers enormous cost savings for tool production, very short implementation times and extremely fast, 100 per cent reproducible set-up operations. Users can bring new progressive components to the market much faster and more cost-effectively, even in very small batch sizes and in a wide variety of versions, and secure decisive competitive advantages."
