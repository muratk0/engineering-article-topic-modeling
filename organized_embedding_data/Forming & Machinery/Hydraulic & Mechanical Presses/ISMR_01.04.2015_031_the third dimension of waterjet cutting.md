# The third dimension of waterjet cutting

[TARİH: 01.04.2015 ISMR]

BYSTRONIC is expanding the spectrum of applications of its ByJet Flex waterjet cutter with a new 3D cutting head. Now users can upgrade the machine platform from 2D to 3D technology at any time.

“With the ByJet Flex machine platform, the variable 2D platform can be upgraded with a modular 3D cutting head. This opens up new business fields for 3D cutting, but simultaneously allows competitiveness in the 2D cutting business to be maintained,” explained Bystronic.

Thanks to this freedom, users can gradually build up orders for 3D cutting. The waterjet cutting system can be equipped with up to two 3D cutting heads that work in parallel. This increases the range of applications and productivity of the ByJet Flex. When order levels are low, it is also possible to equip just a single 3D cutting head. The cutting head can be used for several machines of the same type.

Bystronic’s ByMotion control package ensures integration of 3D technology on the

ByJet Flex and regulates all the cutting applications on the machine platform, simplifying rapid switching between 2D and 3D applications during day-to-day business. ByMotion also supports the user by automatically calibrating height sensing.

Users generate the cutting plans for 3D applications on the ByJet Flex using the Bevel Manager. The software module is tailored to the new 3D cutting head and is integrated into BySoft 7 as an add-on module. See www.3dcutting.bystronic.com ■
