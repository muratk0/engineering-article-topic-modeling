# MC3 – a tube revolution

[TARİH: 01.09.2014 ISMR]

A LOGICAL development of the Linsinger tube cut-off machine, Multi-Cut MC4, which works with four independently-controlled drive assemblies is the MC3 Multi-Cut tube cut-off machine for tube cutting (Ø of between 150 and 660mm). The MC3 stationary tube cut-off machine is particularly suitable for the sampling of tubes’ respective end cuts, used both for welded tubes and seamless tube mills.

“Three smaller circular saws, fixed on a radial revolvable disc, delivers a clean, ready-for-sale cut. This results in shorter cycle lengths with simultaneous engagement of all three saws in the tube and the consequent rotation about 120°; so the pure cutting time for a P110 steel tube of 244 x 13.5mm is about eight seconds. If one sawing station fails, even with reduced line speed the tube line operation can be continued with the remaining stations. Cutting time can be synchronized optimally to the sawblades, which contributes hugely to the cost-effectiveness of the machine,” explained the manufacturer.

Fully automated tool changing is handled by a robot after a set number of cuts. The robot changes all three sawblades in 90 seconds. See www.linsinger.com ■
