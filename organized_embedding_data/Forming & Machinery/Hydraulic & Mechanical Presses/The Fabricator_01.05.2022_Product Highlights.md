Full-coverage lift magnet increases burn table output

Eriez offers the air-operated, burn table lift magnet system. It uses a large, full-contact magnetic surface area to move multiple parts in a single lift. The magnet system also handles skeletons with ease because the magnetic circuit design eliminates gaps on the surface.

According to the company, the system can quadruple burn table production and helps improve safety conditions by eliminating manual handling and the need for operators to walk or climb on the table.

The magnet system can pick up single sheets of material (down to 3/16 in. thick) from a stack for table loading. This eliminates the need for spacers between sheets and separation processes while loading the table.

Software expands ease of use for robot pendant control

Yaskawa offers Smart Pendant software version 2.1, which extends capability for the manufacturer’s Smart Pendant. Building on prior software updates, this version is suitable for quick robotic implementation of basic assembly, injection molding, inspection, machine tending, material handling, and pick-and-place tasks.

Enabling previously unsupported functions, version 2.1 provides a builtin Classic Interface view. Designed for more experienced robot operators, this option lets the end user reset minor and major alarms or edit Concurrent I/O with reduced programming downtime.

The software improves configuration and programming of third-party devices, including the manufacturer’s Smart Packager software development kit. This desktop tool enables third parties to combine multiple components into a single file.

Waterjet system includes intuitive software, improved automation

Hypertherm’s OMAX Corp. has introduced the Opti-MAX, a new generation of waterjet designed to turn prints into parts quickly while relying less on highly experienced operators.

The system includes IntelliMAX software, designed for ease of use and operation quickly following installation, which incorporates decades of proprietary waterjet cutting models. The IntelliVISOR console offers key metrics to optimize operations and complete system monitoring to avoid unplanned downtime. The EnduroMAX pump automatically sets the correct pressure and minimizes fluctuations to help improve component life. And the IntelliTRAX drive system with advanced motion control helps increase system robustness and reliability, requiring virtually no maintenance.

Forklift with rotation on each wheel takes maneuverability to new level

Since Combilift launched its first C8000 model, multidirectional capability has been one of the hallmarks of the company’s material handling systems. Its new product, the Combi-MR4 Dynamic 360, takes multidirectional capability to a new level.

The four-wheel, electric-powered, multidirectional reach truck incorporates the manufacturer’s new Dynamic 360° steering, which provides rotation on each wheel. This steering concept enables operators to manipulate the truck’s positioning and orientation without the need to stop and change driving mode. It can work in forward, sideward, and crab steer mode with seamless directional change while on the move.

The forklift is available in two models, with capacity up to 10,000 lbs. It can operate in aisles as narrow as 8 ft. To maximize vertical storage space in racking systems, the wheel configuration of two drive wheels at the rear and two sets of smaller dual front wheels provides a platform height as low as 15 in.

The unit can handle long loads as well as palletized goods. Features include a highvisibility stand-up or sit-down operator cabin, AC electric power steering, and a multifunction joystick that controls hydraulic mast functions and travel direction.

Laser cutting machine offers high power, maximized control

Mazak Optonics Corp. has released the Optiplex 3015 NEO 15-kW laser cutting machine. It offers automatic adjustment of the beam diameter to cut various materials and of the beam shape to control the concentration and power density of the laser beam.

Equipped with large front and side access doors, the system offers accessibility and ease of operation. Minimized work area restrictions make loading material onto the machine and unloading finished parts easier, says the company.

The new Mazatrol SmoothLx CNC features a large 21.5-in. screen and touch panel. Dual monitors allow multiple applications to run simultaneously. Additionally, the CNC rotates so operators can work at the front or side of the machine.

The system is equipped with a nozzle-centering camera, which provides visibility of nozzle location while adjustments are made on the torch, and cameraassisted part nesting, which automatically determines the arrangement of parts for cutting on remnant material. It also features intelligent setup, monitoring, and cutting functions to help optimize laser cutting performance.

Parts washer uses water-based surfactant blend

Lawson Products offers the Torrent parts washer. It combines heat, chemistry, and pressure to clean parts five times faster than traditional automatic parts cleaners, according to the manufacturer.

Unlike parts washers that use petroleum or chlorinated solvents, the machine uses a water-based surfactant blend to clean hard-to-reach points. This solvent-free approach reduces employee risk while cleaning 90% of parts within one minute.
