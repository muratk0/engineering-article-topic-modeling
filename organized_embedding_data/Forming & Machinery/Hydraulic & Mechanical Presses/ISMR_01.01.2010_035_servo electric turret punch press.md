# SERVO ELECTRIC TURRET PUNCH PRESS

[TARİH: 01.03.2010 ISMR]

Dimeco Alipresse’s servo electric LinaPunch MC-E is a new generation coil-fed turret punching machine. This new punching machine has been designed to improve productivity with higher speeds, as well as give more flexibility and reduce by up to 50% energy costs in high quality high volume sheet metal fabrication, especially for metal furniture and white goods applications.

The main feature of this machine is that only the tools move, which enables a higher punching rate using less energy. The 2 x 20 tonnes servo electric punching power is transferred to the ram through a knuckle system for a softer punching action and programmable stroke. It is designed for coil strip of up to 34” wide using a one-side tool holder and up to 68” using two-sided tool holders facing each other.

Options include punching tonnage monitoring that includes automatic tool brake control and tool lubrication with oil injection through the top of the tool using programmed oil quantities.
