# HYBRID THREADFORM TOOL

[TARİH: 01.02.2013 ISMR]

MATE’S NEW HYBRID threadform forming tool for punch presses provides a new solution for fastening two pieces of sheet metal together without tapping or secondary operations. Designed for use when the material thickness is greater than the screw pitch, Mate’s Threadform forming tool thins the material in the centre of the form, creating a threadform helix so that the material fits between the pitch of the screw head in just one operation.

At the heart of this specialised Mate tool is an upper and lower insert machined with a profile that precisely matches the thread helix of the screw thread. The geometry of this part is modelled electronically by a Mate applications specialist using its advanced CAD software, creating a three-dimensional solid model for specific requirements.

“The benefits of using the forming tool include the elimination of tapping and other labour-intensive secondary operations such as welding fasteners to sheet metal. The tool also eliminates debris when tapping and reduces component cost by eliminating the need for special fasteners,” Mate told ISMR.

“Many Mate tooling users are combining Mate’s hybrid threadform forming tool with other Mate special applications tooling for their fabricating projects. For example, by combining use of the forming tooling with EasyBend™ for forming corners, EasySnap™ to break apart pieces from sheet, users can reduce set-ups, maximize machine usage and increase profitability.”
