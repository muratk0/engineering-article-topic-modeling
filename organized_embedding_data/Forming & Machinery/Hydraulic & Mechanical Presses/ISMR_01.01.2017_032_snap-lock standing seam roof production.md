# Snap-lock standing seam roof production

[TARİH: 01.01.2017 ISMR]

ROLL FORMING TECHNOLOGY specialist, AJV-Machine, has launched a record-breaking sheet metal profiling solution, AJV FastFix™. The line represents a new kind of technology for the production of snap-lock standing seam roofs.

“For the first time in the production of this roof type, all processes are fully automatic. Only one line operator is needed to control the entire line. FastFix™ is able to produce the roof at 500 m²/h, which is triple the amount compared to traditional machines. This massive volume is achieved without worrying about the machine's operating condition, because FastFix™ is designed to endure in constant heavy-duty production," said the manufacturer.

“FastFix™ can be integrated to any Order Management System (OMS). This feature forms a solid and systematic foundation for

orders and eliminates human error relating to manual order processes. The FastFix™ system reads the dimensions and other order details accurately and acts accordingly. The system creates a database so that each profile produced is traceable with any search criterion. In all, FastFix™ streamlines roof production from order management to quality control. It is equipped with an easy-to-use, intuitive interface so that any operator can achieve great profiling results.

The profile produced by FastFix™ has capillary break as a built-in feature, eliminating capillarity. The profile also has stiffeners as a built-in feature, which make profile overlapping stronger and more supportive for roof safety products.
