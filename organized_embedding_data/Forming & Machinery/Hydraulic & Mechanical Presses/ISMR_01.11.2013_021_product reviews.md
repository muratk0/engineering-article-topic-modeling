# PRODUCT REVIEWS

[TARİH: 01.11.2013 ISMR]

The machine has more than 100 dynamic axes which are constantly changing position during the roll forming operation as well as over 40 fixed axes which are positioned according to the profile to be produced and will constantly be maintained in position during the process. Each axis is driven by servo-motors, with position control in a closed loop, with each axis moving in a different manner to the other axes depending upon its physical position along the machine.

The choice of electronic components is important and control software was developed that could control the positioning of all the dynamic axes, following the progress of the strip inside the machine with precision, reliability and repeatability.

Movement error of just one single element, during the roll forming of a 7mm thick beam, could cause serious damage. For this reason, a continuous monitoring system was developed which immediately stops all operation as soon as any anomaly is detected.

The machine is able to roll form pieces of different shapes and thicknesses and is not linked to a fixed vehicle design. Vehicle manufacturers have various production models and various chassis and must be able to move quickly and safely from one product to another through easy programming.

To do this, STAM developed a CAD/CAM system which, starting from a CAD drawing in dwg or dxf format from the customer, converts the drawing into a machine programming file. The software automatically calculates the positions of the various roll forming stands and the positions of the guides while the profile is being processed in the roll forming machine.

During the test phase of a new product, as in all other automatic self-configuring roll forming machines, some adjustments might be needed to the positioning of the forming rolls. Once the best set-up is chosen, this will be saved in the control system so that it can easily be recalled using a product code number for the new product produced.

“The machine was built and tested at STAM with excellent results. The customer measured all the pieces produced, checked the repeatability of the process and compared it with the current process,” STAM told ISMR. “At STAM, we work with an eye on the present as well as on the future”. ■
