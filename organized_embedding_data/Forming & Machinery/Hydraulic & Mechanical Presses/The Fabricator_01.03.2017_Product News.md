Drilling system employs three independent drilling heads

Voortman offers the V630 drilling system with three independent drilling heads, each with its own automatic tool changer with five tools. The machine can drill both flanges and the web at the same time to help reduce working hours and operating costs, the company states.

The system also offers layout marking on four sides. With drills that mark only three sides, assembly personnel need to measure manually on the fourth side of the profile. A separate unit that uses the same tool as the drilling line can be installed in the line for layout marking the bottom of the profile.

When all files are selected, profiles are loaded on the connected cross transports, and correct tooling is available, this machine can run without an operator for a considerable amount of time, the company states.

Robotic bending system processes large parts

The HG 1303 Rm robotic bending system from Amada was designed for processing large parts, which typically require two operators to safely handle or are difficult to manage by a single operator. The press brake features an advanced crowning system in the lower beam combined with an automatic bend angle measurement system for increased precision.

The Dual Servo Power (DSP) drive system is engineered to increase approach, bend, and return speeds. The rigid frame design features a large open height; the increased distance between tooling and greater stroke length yields a larger processing area, enabling deep box bending while making part extraction faster and easier.

A Thickness Detection System (TDS) maintains bending accuracy while processing materials that vary in type, thickness, and grain direction. TDS reads variance of material thickness and compensates depth position automatically.
