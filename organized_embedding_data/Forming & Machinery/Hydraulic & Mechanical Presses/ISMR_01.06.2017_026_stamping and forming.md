# Stamping and forming

[TARİH: 01.06.2017 ISMR]

Below: GRM-NC servo-controlled stamping and forming machine "WITH OUR GRM-NC stamping and forming machine, users can now produce motor housings and their variants with higher productivity and more flexibility. Thanks to extremely fast set-up and re-tooling (in less than one hour), the GRM-NC is suitable for small and medium batch sizes. The latest servo technology, in conjunction with the intuitive control technology of the Bihler VariControl, are also features of this machine," Bihler told ISMR recently.

With an integrated fully automated positioning unit, NC processing units can now be aligned in radial and linear directions. After tool assembly, the production parameters programmed into the VariControl system can be implemented and production started.

"The GRM-NC can be equipped with the standardised LEANTOOL. This modular tooling kit enables easy, fast and cost-efficient implementation of new forming tools for the production of stamped and formed parts. Users benefit from extremely short implementation times, with costs reduced by 70% compared to forming tools on mechanical machines, as well as a very fast 'time-to-market' for new products, even for the smallest batch sizes," added Bihler.

The GRM-NC is fully compatible with machines of the mechanical GRM series. Existing tools from these machine types can be adapted and optimised for the servo-controlled GRM-NC. This, said Bihler, means that output can increase by more than 300%, batch sizes can be processed in half the time and changeover times are shortened by up to one tenth.
