# Rolling software

[TARİH: 01.09.2020 ISMR]

AMB PICOT HAS been designing and manufacturing roll bending machines for more than 150 years. The French manufacturer has always emphasised the versatility of symmetrical 3-roll technology that enables double pre-bending (without turning a metal sheet), does not laminate the sheet and is precise in bending the material.

“However, aware that these machines require special expertise, we launched our Easyroll® software three years ago to help operators with rolling operations,” said AMB Picot.

“The software is based on a database of rolling algorithms,” it added.

This database integrates the most common material data on steel, stainless steel and aluminium, with the option of adding different materials, such as composites.

“The software is constantly evolving. The recent 3.0 upgrade allows the reading of files in .DXF format and the automatic transmission of material corrections to enrich the material database and improve the creation of programs along the way,” it concluded.
