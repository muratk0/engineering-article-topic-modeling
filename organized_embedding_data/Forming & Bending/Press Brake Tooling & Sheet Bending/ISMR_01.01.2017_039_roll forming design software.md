# Roll forming design software

[TARİH: 01.01.2017 ISMR]

THE DEVELOPED LENGTH of each arc segment and, with it, the strip width is generally calculated on sheet thickness, bend radius and angle. In reality, however, there are more influencing factors such as the material used, the bending method and the bend angle sequence.

“Recent research on this by the PtU at the Technical University of Darmstadt (Germany) aligns with the experience of roll form designers. These factors cannot be handled by a universally valid calculation method, but need to be defined individually and empirically. In the new release of our roll form design software, UBECO PROFIL, a separate calculation method can be applied to each arc segment. The user can select between a standard method (such as Oehler, DIN or Centerline) or define user methods that can be modified with empirical corrections. The latter is important in case larger angle increases are necessary,' explained software specialist, UBECO.

“If the roll forming tools are verified using FEA (Finite Element Analysis) simulation, the quite short sheet section must be threaded correctly into the roller stands. In the new release of UBECO PROFIL, the user can select between several options to enable correct threading. If pre-cut blanks are roll-formed, guiding and chamfering can be switched off to simulate this process correctly." See www.ubeco.com■
