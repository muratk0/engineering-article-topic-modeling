# BENDING SOFTWARE

[TARİH: 01.09.2010 ISMR]

LVD Company nv now offers CADMAN-B 3D version 7.2 offline programming software for its PPEB and Easy-Form Series of CNC press brakes. CADMAN-B 3D ver. 7.2 provides enhanced features to simplify part programming and is compatible with LVD’s CADMAN CNC control and CADMAN Touch touch-screen controller. The new release also supports robotic bending applications.

CADMAN-B 3D ver. 7.2 provides a multiple machining function, which defines a bending solution that can be stored, copied and applied to other press brakes, thus minimising programming and machine set-up time. The latest release also incorporates additional automatic features to speed programming time, including automatic splitting of tool setup and programs.

Automatic gauging functions, including comfort gauging correction, backside gauging avoiding Y-axis turning for long parts, and tolerant parallel gauging significantly reduce setup time by eliminating manual operations. Parametric scaling automatically adjusts the bending solution when part dimensions have been modified. Ver. 7.2 also provides a SAT file preview for quick, easy reference when programming. A multiple parts working environment allows multiple parts to be viewed without loss of the working environment.
