# Keep it simple

[TARİH: 01.10.2014 ISMR]

THE TUBE bending machine manufacturer, Schwarze Robitec, has developed a new rapid clamping system, dubbed Quick Tool Unlock, for tube bending machines according to its engineering motto, ‘Keep it Simple’. This allows quick and simplified changing of the bending formers, without tools, and noticeably reduces set-up time.

The rapid clamping system features a split tension rod with clamping lever as well as a swivel device. While, in most models, the continuous tension rod to the swivel cross arm needs to be unscrewed at the top of the bending former for a tool change, the procedure is much simpler with the Quick Tool Unlock. Here, only the clamping lever is actuated and the connection to the swivel cross arm is therefore disengaged. The swivel device can subsequently be opened so that the bending former is exposed to the top. When automatic tool clamping is engaged, the bending former can be removed without any difficulty. There is no longer any need to unscrew the bending former. All connections from static to rotating parts are made using rolling bearings which contribute to the durability of the machine.
