# ‘Art to part’ robotic bending

[TARİH: 01.01.2021 ISMR]

LVD has introduced Ulti-Form, a new robotic bending system featuring an automated tool-changing press brake designed to keep bending productivity high and handling small batches and long production runs with low changeover time.

“Ulti-Form features a 135-ton press brake designed using the ToolCell platform, our automated tool-changing press brake, integrated with an industrial robot. The press brake houses a built-in tooling warehouse and uses a gripper mechanism in the machine’s back gauge fingers for quick and efficient tool change,” LVD told ISMR.

The press brake and robot work together in synergy to keep changeover time to a minimum. As the robot picks up the first workpiece from the input stack and centres it, the press brake completes the tool change. Ulti-Form handles parts from 50 x 100mm up to 1200 x 800mm, weighing up to 25kg.

“Ulti-Form is automation that’s easy to use with a fast ‘art to part’ process, thanks to our powerful programming wizard. Programming of both the press brake and robot is handled offline and no robot teaching is required. CADMAN®-B software automatically calculates the optimal bend program. The robot software imports all bending data and automatically calculates all gripper positions taking into account gripper force, collision detection and robot reachability. It generates the fastest collision-free path for the robot across the complete bending operation. The system’s database contains all the set-up information needed for the press brake and robot so that Ulti-Form is quickly readied for production,” explained the manufacturer.

The Ulti-Form robot gripper is an autoadapting design engineered by LVD (patent pending). It can accommodate several part geometries, automatically adjusting to the workpiece size. This allows a series of different part geometries to be processed without the need for a gripper change, keeping production continuous and uninterrupted.

Equipped with LVD’s Easy-Form® Laser adaptive bending system, it adapts to material variations (including sheet thickness, strain hardening and grain direction), automatically compensating for any changes.

“Ulti-Form is a modern automated bending system with a small footprint of 8 x 10m. The system includes three input pallets, a large output zone and drop zone for small parts, an automated pallet dispenser and conveyor belt to transfer full pallets out of the system. It can operate automatically or in manual mode. Manual operation can be used for very complex parts and small batches,” added LVD.
