# Faster bending for small batches

[TARİH: 01.08.2022 ISMR]

SafanDarley has added the E-Brake C 200T Ultra with Tool Mate to its press brake range.

“The Tool Mate is an external automatic tool changer and offers great time savings when producing small batches," SafanDarley explained.

The servo-electric E-Brake C with 200-ton pressing force and a bending length of 4300mm is built with a C-frame, to enable automatic tool change.

"The Tool Mate is very intuitive, with tool changes made via the SafanDarley E-Control. The correct tool settings can be loaded and used directly on the machine from our AutoPOL offline software (or other independent offline bending simulation software)," the Dutch sheet metal bending specialist told ISMR.

Above: The servo-electric E-Brake C. Below: Tools can be rapidly placed in the correct position.

The high-precision changer ensures that tools are placed in the correct position. Intelligent software automatically makes any necessary changes so that tools, from the previous tool set-up, can be reused. This means considerably shorter tool changeover times for users. The tool storage magazine has a capacity for 32-, 52- or 60 metres of tools.
