CAD/CAM software suite for metal fabrication updated with new features

SigmaTEK Systems has introduced version 20 of its SigmaNEST product portfolio, offering many new features.

A new Launcher provides a common, customizable desktop platform from which users can access core SigmaTEK products and ecosystem applications such as license manager, database utilities, and help resources. The Launcher also displays a live social media feed to help users stay up-to-date with the latest product information, tradeshows, and educational webinar schedules.

Other enhancements include support for part priority nesting, nesting of filler parts, and nesting of mini-sheets or mini-nests. A new CAD Import Plus module is available that does not require a local CAD installation to import a variety of file formats, including SOLIDWORKS

®

, Solid Edge, Creo, Inventor, and NX. In addition, the software adds feature recognition (drilling, partial-depth pockets, bevel) for STEP files.

Bevel capabilities such as advanced toolpath generation and rule-based corner transitioning have been added. Users now can import part files with complex bevels and apply NC directly to the 3D model in an interactive 3D viewer to help ensure safe and accurate toolpath generation and better program verification.

Other developments include expanded support for the TRUMPF TruMatic 1000 Fiber punch/laser machine, laser precutting for creating complex threaded holes on combination machines, and the use of raw sheet edges as the part edge with improved height detection and probe cycles near the sheet edge.

SigmaQUOTE, a new integrated job quoting tool, replaces the software’s previous Jobs module. Powered by SigmaMRP, it uses the product’s quoting functionality to allow users to manage companies and contacts, generate quotes for new projects, and turn quotes into work orders for production.

Further improvements to the 3D suite of applications for tube, bar stock, 3D models, and sheet metal forming include the ability to convert multipiece common- line gores into a single no-kerf, common-line part within SigmaDEVELOP, a 3D system for standard ducting and HVAC geometry. SigmaUNFOLD flattens the 3D patterns and allows them to be manipulated for cutting and bending operations. An automatic slit-creation option adds a slit to an otherwise solid part so it can be unfolded into a flat pattern that can be processed on either cutting or press brake machines.

For SigmaBEND, the new version includes a new radial menu with shortcuts for editing the toolstations, backgauges, and the part itself, as well as improved sequencing and backgauge options. In addition, a new manual stationgeneration tool allows for simplified manual tooling setup. SigmaTUBE generates nests and NC code for tube and pipe cutting on laser and plasma machines, and the software includes support for new inventory profiles and tab and notch enhancements.

Color Offload, a tool that uses color-coding to track parts by next operation, has been updated with the ability to filter by program status as well as document management capability. SimTrans, a transaction manager that links SigmaNEST with other business systems, can be used to create or load parts, manipulate orders, and update inventory in real time. New transactions have been added for managing jobs, and email notifications can be received for regular status updates or invalid parts.

Tabletop marker offers touchscreen programming

Rocklin Mfg. has introduced the FlyMarker

®

mini Station tabletop marking unit. The electromagnetic, 120-V batteryoperated marking unit from Markator features a capacitive touchscreen for programming. Its large marking window and adjustable force settings deliver permanent dot peen marks on materials from plastics to hardened steel (up to 63 HRC). The stronger force settings are designed to withstand surface treatments such as galvanizing and sandblasting. The unit automatically adjusts to round or uneven surfaces with up to 5-mm height differential. A variety of part heights can be accommodated through the rocker arm handle design. Software programming allows character heights from 1 to 100 mm.

Marking files can be transferred via USB or Ethernet or programmed and stored on the unit. Autonumbering, time/date stamps, letters, numbers, and characters come standard, with logos and data matrix codes available as options. An integrated laser pointer coupled with a preview screen delivers a clear simulation of the proposed mark to help eliminate errors.

Wire electrode doubles as sensor

Fronius has introduced the WireSense assistance system for robotic welding. The wire electrode is a sensor that checks the component position before each weld. Detecting actual sheet edge heights and positions, it helps compensate for manufacturing inaccuracies and improve welding results, the company reports.

The technology does not require any additional sensor hardware components. The welding torch scans the component with a reversing wire movement, and the welding system sends the height information and the edge position to the robot. If a lap joint is being welded, the edge position can be defined, and the system can react to deviations. The robot adjusts the weld seam process based on an application-specific program.

By evaluating the height information, the robot can determine both the course of the edge and the actual edge height. It also can determine the air gap between the sheets. Edges are detected from a height of 0.5 mm.

The electrode can be used with steel, stainless steel, aluminum, and other alloys.
