# THE EYE OF THE NEEDLE

[TARİH: 01.11.2011 ISMR]

ISMR examines the latest new CADCAM and simulation software developments.

Among the technical industry trends that software manufacturer NUM is currently seeing in the CNC sector is an emphasis on energy efficiency, with more use of drive systems with a shared DC bus for recovery of power.

The use of direct drive configurations is also increasing in the push for higher performance and quality. This approach, along with other techniques such as drives with anti-resonance capability, is featuring in a growing number of machine builder strategies for maintaining precision while saving on the scale of the machine’s underlying metal-based framework and rigidity.

A longer term trend that NUM sees is some movement away from the G-code programming language and towards more direct linkages between CAD and CNC control. A more direct path from design to manufacture is something that NUM has already pioneered for more than 20 years with its NUMROTO software for tool grinding machinery. This package features an integrated modelling-simulation-interpolation chain that provides a WYSIWYG output.

“It avoids today’s sequential CAD-to-CAM and CAM-to-CNC translation stages with data format changes, emulations etc. which almost invariably have to be followed by an optimisation phase before a part is able to enter production,” it told ISMR.

The FABTECH 2011 exhibition in November will be showcasing many software vendors including ERP, MRP, supply chain, preventive maintenance and other software products.

Intergraph CADWorx Plant Design Suite 2012, the latest version of Intergraph’s design solution for mid-market and AutoCAD-based projects and workgroups, is now compatible with AutoCAD 2012, the latest AutoCAD release from Autodesk.

CADWorx 2012 builds on recently added capabilities and performance-enhancing features. CADWorx Plant Professional now includes a new discontinuity palette, used to show component discontinuities and overlaps in the model, with full reporting capabilities. A newly improved pipe support module provides greater flexibility in the placement of pipe supports, with bills of material capabilities extended to pipe support subassemblies.

HVAC and cable tray enhancements include the addition of manufacturer catalogues and live database links to components. Improved steel capabilities include the ability to create plate from any single-line shape plus enhanced CIS/2 import to provide better integration with Intergraph FrameWorks.

JETCAM has released version 16.20.02 of its Expert CADCAM and nesting software. The new version contains several significant features, a new entry level product and many performance enhancements. JETCAM Expert is now available in three versions, Expert 1, Expert Premium and a new version known as Expert Lite. This is aimed at the OEM and used machine tool market where customers only require basic functionality to start with, but want a clear and simple upgrade path to a semi/fully automatic programming system in the future. It still includes many of the advanced features of its sibling products, but excludes some of the automation. It is also limited to supporting one machine; however, a free-form (true shape) nesting module is available.

The latest version of Lantek’s Expert Cut software, designed specifically to integrate laser cutting machines with the majority of CAD platforms, achieves high component output and fast turnaround times. The Lantek Expert Cut suite is a flexible CADCAM system specially designed to automate the programming of sheet metal cutting machines (oxicut, plasma, laser, waterjet). The laser cutting technology modules are specific for each type of machine, providing management of reduced lead-ins, lead-in with runback, customised piercing, sprintlaser, microjoints, microwelds, head management, contour attributes, manual and automatic extractions etc.

All the options of Lantek Expert are fully integrated in a single program, so designing a part, importing, nesting (automatic or manual), generating the cut (automatic or manual), generating the CNC and looking at the sheet metal store can be done from the same program without switching between programs.

Lantek's latest Lantek Flex3d software makes it easy to import and unfold 3D data from leading CAD systems. The system can unfold tubes, steelwork and greatly simplifies the programming of cutting machines with 5-axis capability, using the advanced algorithms within the software.

The Lantek Integra ERP system is designed for sheet metal and steelwork applications and, in its latest version, is fully web-enabled, allowing companies to manage and automate business processes in an Internet or Intranet environment from any location or time zone using the most popular web browsers and mobile devices such as the iPad.

Radan is powerful sheet metal CAD/CAM software, helping customers increase their material utilisation and reduce inventory. Radan is a principal brand of Planit Software. New features allow Radan 2011 R2 to integrate more with users processes. New nesting functions include giving more control over specific parts and sheet sizes, to ensure that the final nest takes the user’s individual requirements for that particular job into account.

There is also a new option of excluding certain sheet sizes from the nester, giving the user the ability to relate what he is doing offline to what is happening on the shop floor.

Radan 2011 R2 features a technology which allows the nester to use multi-part symbols to produce the correct number of parts.

A new “Publish Remnants” function allows remnants to be published into a central folder. The user decides whether to publish them as soon as the nest been created on the computer or whether to wait until the parts have been manufactured. Radan 2011 R2 also creates a utilisation premium for remnants.

SigmaTEK Systems confirmed that SigmaNEST Version 9.1 contains a combination of improvements in intuition and efficiency enhancing features. SigmaNEST 9.1 makes advanced programming tasks simple and more automated. This release introduces optimisation tactics that use brand new features like iPierce, HDX precision plasma setting, improved import functions, NC sequencing and more.

“iPierce creates an eyelet into the skeleton as it cuts the part, then places the next lead-in in the eyelet area, eliminating the need for a pierce. Reducing pierces dramatically decreases the cycle time to cut a nest, especially when processing thick metal. Another benefit of pierce reduction is the elimination of slag where parts have been cut,” the company told ISMR.

“SigmaNEST HDX processes parts specifically for precision plasma cutting. It assigns special lead-ins and lead-outs to each part to eliminate divots in small holes. SigmaNEST adjusts gas pressures, plasma amperage and height controls while it generates the cutting program. It automatically calibrates the NC toolpath to achieve a balance between pierce holds, feed-rates and advance-of-movements, resulting in cylindrical, taper-free holes. SigmaNEST HDX can be used with any plasma machine capable of advanced command messaging, auto gas and height control to produce superior hole quality, even at a 1:1 ratio.”

The new import functions are an interactive dialogue that allows users to scale parts and gives them the ability to toggle and show errors within the part’s geometry before importing the parts. It has also added the ability to import from vector-based PDF files. ■
