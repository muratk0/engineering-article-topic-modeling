# Measurement and evaluation software

[TARİH: 01.10.2020 ISMR]

3D METROLOGY specialist GOM has released its all-in-one GOM Inspect software to use along the entire workflow – from measurement to inspection and final report. All applications are now fully integrated and can also be customised using in-house scripts.

GOM, a ZEISS Group company, provides optical 3D metrology systems. GOM software features free inspection functions that are updated every year and can be extended through the addition of paid modules.

GOM’s new software platform, GOM Inspect Suite, groups together all applications and offers full integration, from 3D data capture to reporting, as well as several workflow efficiency improvements, greater flexibility and process security, and reduces the need to invest in training. The 2020 software release includes structural improvements as well as additional functions.

“The GOM Inspect Suite 2020 also offers systemindependent evaluation software for 3D measuring data generated by fringe projection scanners, laser scanners, coordinate measuring machines and other measuring machines. Users can work with polygon meshes, inspect measuring data and produce reports as easily and efficiently as ever. Paid modules, such as GOM Inspect Professional, support, for example, parametric inspection and simplify the entire measurement workflow through templates for measuring procedures and inspection reports (‘Smart Teach’ functions),” the software specialist told ISMR.

“For the first time, the 2020 release includes a set of functions for volume inspection of voxel data generated by computed tomography (CT) scan in the free standard inspections. An innovative 3D volume renderer supports the visualisation of interior structures, geometries and shrinkage cavities. Assembly situations and virtual sectional views can also be analysed using the CT data.”

“An intuitive Kiosk Interface makes it easier for non-specialists to get started with measurement automation. Online training courses enable people to take part from anywhere at any time and supplement the classroom seminars,” concluded GOM.
