New versions of nesting, automation software released

Jetcam has launched new versions of its core nesting software for CNC punch and profiling technologies—Jetcam Expert—and Jetcam Orders Controller (JOC) automation software.

In the nesting software, Jet-Cut applies fly cutting during the tooling process, automatically identifying areas that can benefit, and Jet-Optimizer creates the optimal cutting path while avoiding previously cut areas. A new component simulator allows for users to simulate the cutting of a single part, rather than having to create a nest with one component. The software also has a new report designer that allows users to create complex custom reports quickly.

In JOC, a new tool graph displays the number of tool hits per nest, which can be useful when calculating the remaining life of a tool. Users now can filter components based on whether they are tooled for a specific machine and filter assemblies that include one or more component names.

New features added to tube software

Hypertherm has announced an update of Rotary Tube Pro™ software that simplifies designing and cutting tube and pipe parts, with no 3D CAD experience required.

The update includes a number of new features designed to speed the programming process. For example, automatic nesting now is standard, allowing software users to nest multiple quantities of the same part or different parts on stock tube. Users can add parts to the part list and build a stock list for nesting, maintain the seam orientation during nesting, and choose how the software selects stock.

Other new features include the ability to store multiple parts and nests, plus an advanced edit feature that allows users to adjust preferences manually, such as lead size and position, along with cut sequence. The software also includes features that allow users to pin commonly used lead styles to the top of the list for quick access and offers more powerful reports.

Tool changer integrated into press brake

Bystronic offers the Xpert press brake with integrated tool changer system, which allows the press brake to swap tools automatically for quick parts bending. The tool changer sets up the machine with the upper and lower tools that are required for the job. When done manually, this step takes up to 70 percent of the entire bending time.

The 6-axis robotic arm integrated in the press brake accesses the tool magazine, which also is integrated within the machine and houses a generous supply of bending tools. The entire automation system is located within the press brake, protecting the robotics system and tool magazine.

In combination with the tool changer system, the press brake offers a bending length of 9.8 ft. The available press capacity is 150 to 320 tons. As standard, the machine comes with an intelligent bending process control and fully automatic crowning. Both functions enable a variety of parts to be bent with repetitive accuracy, says the company.

Low-manganese stick electrodes introduced

Weldcote Metals Inc., a division of Zika Group, has introduced WCM low-manganese SMAW electrodes. The patented line has a flux composition that supplies weld metal with lower manganese content, decreasing manganese vapor emissions by as much as 60 percent in comparison to standard electrodes, the company says.

The electrodes are available in three AWS classifications. E-6011 is an all-position, AC/DC electrode for deep weld penetration for root passes for welding pipes and general structural welding. E-6013 is an allposition, AC/DC electrode typically used for welding cleaner steel. E-7018 H4R is a low-hydrogen, humidityresistant, usually DC, all-position electrode used for many metals. All offer a stable and smooth arc, and easy slag detachability, the manufacturer reports.

Option helps simplify fiber laser process monitoring

The new HighLight

®

SQD option for Coherent HighLight fiber lasers provides cutting and welding systems integrators with a turnkey means to implement process monitoring.

The option comprises process sensors integrated directly into the company’s fiber laser connectors, which detect back-reflected laser power and visible-spectrum process emissions. These signals, which are provided in either analog or digital CAN bus form, can be used to detect various key process events. For cutting, these include piercing end, cut interruption, and selfburning during piercing. For welding, the monitor can indicate incomplete penetration, blow holes, contamination, and gap detection for overlap joints.
