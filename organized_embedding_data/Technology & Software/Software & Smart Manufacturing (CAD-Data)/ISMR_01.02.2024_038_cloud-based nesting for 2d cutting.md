# Cloud-based nesting for 2D cutting

[TARİH: 01.02.2024 ISMR]

Alma is a leading developer of CAD/CAM software for sheet metal working, cutting and robotics. With over 40 years of experience in cutting optimisation and sheet metal CAM software, Alma has developed Nest&Cut, an automatic nesting subscription-based web application for 2D cutting.

"Nest&Cut enables any company that needs to cut sheet metal or any flat materials, wherever it is in the world, to easily access high-performance automatic nesting functions for reducing raw material costs, without investing in a costly solution. Today, Nest&Cut has several hundred users worldwide and now the application makes it possible to generate ISO programs for simple NC cutting machines (20 post-processors are already available in Nest&Cut's web app)," Claire Macabies, marketing manager for nesting applications at Alma, told SMR.

In a few clicks the user sends DXF format geometries, prepares the data (quantities of parts, material formats etc.) and then starts automatic nesting in the cloud. Seconds later, Nest&Cut delivers the optimised cutting plans in DXF format or NC code for some cutting machines, ready for cutting. All the nesting data is listed in a PDF document.

"Four years ago, we launched Nest&Cut as a web app for nesting and a new business model in Saas (software as a service) and cloud. It now has customers all over the world and offers nesting and cutting, with many machine tools now driven directly with Nest&Cut (integrated into the machine's software package). It offers substantial time and money savings to users and now includes several new advanced cutting optimisation features," explained Claire Macabies.

## Advanced cutting optimisation features

Nest&Cut is a completely automated application and has been designed for ease of use. It is available online from any device connected to the web, with nothing to install or configure. Monthly or yearly subscriptions are possible. Simplicity of use was a key requirement from the start.

"Application enhancements are integrated transparently for the user, who has no maintenance or upgrade charges to pay. Nest&Cut does not require any training and users do not have to invest in an expensive programming software, with virtually no human resources needed," outlined Alma.

"It is an intuitive premium web app and users can benefit from powerful nesting features, integrated functionality and a comprehensive nesting library which has been built up over many years," added Claire Macabies.

Several advanced cutting optimisation features are now available, as listed below:

■Automatic parts cleaning: "The quality of DXF or DWG geometries is a recurring problem in CAM. Complex and extremely time-consuming operations are required to be able to use these geometries for cutting. One of Nest&Cut's specific features is the inclusion of advanced functions for automatic cleaning of DXF or DWG geometry to avoid these problems. To do this, Nest&Cut performs automatic relinking and removal of autointersections," explained Alma.

■True shape automatic nesting: Nest&Cut chooses the best part orientation amongst allowed orientations. Part rotation can be customised, globally and individually. Part recesses are used to recursively nest parts in other parts (“inside-part nesting").

## ■Multi-format nesting: Nest&Cut performs global optimisation on multiple sheets to save more material. Sheets of different sizes can be used. To improve productivity in case of more parts, Nest&Cut manages nesting multiplicity: the application generates a few different layouts that will be used several times.

## ■ Cutting order generation: After optimising nesting layouts, Nest&Cut generates cutting trajectories for a large variety of machines with an optimised sequence to reduce cutting time. It can also output nesting layouts in DXF with optimised part cutting order.

■Re-nest existing layouts: Nest&Cut can read and improve DXF or DWG nesting layouts that were created using another system. It can nest more parts on the same material sheet, thereby reducing material scrap and cost.

■Ready for production: Nest&Cut exports DXF nesting layouts or optimised NC code (AMADA; Bystronic; Flow; Hypertherm; CypCut; GCode and more coming). An interactive simulation gives users a look at the code and a detailed PDF reports helps workshop operators to control production.

## A flexible focus

"Nest&Cut is for cutting subcontractors or manufacturers (end users) who do not own high-performance nesting software but wish to improve their recurring or occasional material yield. They also do not want to invest in on-site CAD/CAM software as acquisition and maintenance costs are too high, they have insufficient human resources and learning takes too long etc.," explained Alma.

"It can also be used to accurately estimate material consumption and corresponding costs. The application is available without long-term commitment via a monthly or annual subscription. So that users can test the efficiency of Nest&Cut and then decide to subscribe, we are offering one month of use (free of charge) with full access to all the app's functions," continued Alma.

Nest&Cut can also be integrated by cutting machine manufacturers or resellers. It is available in seven languages (English; German; Italian; French; Spanish; Japanese and Brazilian Portuguese) and will soon be available in other languages. Technical support, with rapid response, is also provided.

"New post-processors for CNC cutting machines will be added in the Nest&Cut app as they become available, as well as increasingly specialised sheet metal functions (which have been integrated into our CAM application software) such as optimised cutting sequence; lead-in/lead out assignment and settings; bridges between parts; micro-joints etc.," concluded Alma.
