# THE PART PROCESS

[TARİH: 01.06.2018 ISMR]

ISMR SAYS: “Elkuch was one of the first adopters of JETCAM’s parametric programming module”

Elkuch Eisenring, based in Switzerland, is part of the Elkuch group of companies, and one of the largest sheet metal manufacturing companies in Switzerland. The company has relied on JETCAM Expert sheet metal software since the early 1990s, when it was supplied along with a Finn-Power CNC punch press with Right Angle Shear.

Since then, JETCAM has driven the company's Bystronic laser cutting systems and TRUMPF punch and punch/laser combination machines.

Automation software has helped a Swiss manufacturer to create sheet metal parts dynamically, using parametric programming.

## Parametric programming

Elkuch was one of the first adopters of JETCAM's parametric programming module. The company manufactures a range of products including fireproof doors and switchgear cabinets. All products are based on scalable templates which are then tailored to the customer’s requirements. JETCAM's parametric programming can generate a component file using a simple script that takes general parameters (such as overall height, width, number of hinges required etc.) and then automatically applies standard rules to create the component, which is then ready for nesting.

Steffan Rueger, Production Manager, Elkuch Eisenring, explained; "Initially, most of our products were standard, so we would simply take an existing product template, which would consist of a parametric program for each component, and then run an automatic parametric script to pass all of the variables for all components. Component files were created in seconds and were then ready for nesting."

Over time, however, the business changed and customers demanded more bespoke products.

Rueger noted; "Previously, around 80 per cent of products manufactured were standard. The remaining 20 per cent required customisation to the parametric programs, which left open the possibility for error and subsequently scrapped components. We have an Oracle database-powered MRP system which already had all the parameters required to populate JETCAM's parametrics, so we decided to write an interface in-house in Visual Basic that could automatically create all the necessary parametric programs. We’re now in a position to create a bespoke product in the same time as a standard one – about 50 per cent of the time it previously took, and we’ve also reduced the number of standard templates from over 500 down to around 30."

In 2014, JETCAM released Automatic Sheet Processing (ASP), which Elkuch received free as part of its annual maintenance contract. ASP allows an entire nest of components to be automatically tooled, with sheet destruction applied simultaneously.

Rueger noted that this solved an issue it was having with unloading; "Unloading errors could often occur if the skeleton was left intact, resulting in damaged components, so previously we would manually destroy the sheet. With ASP, for all but our most complex nests, we can tool the entire nest and destroy the remaining sheet very quickly. Overall, ASP reduced our programming time by a further 15 per cent."

## Finding a workaround

In 2015 Elkuch purchased a TRUMPF 5000 punch press, also taking the decision to investigate improving its labelling of components. Previously, it purchased adhesive labels with non-residue glue, which Rueger explained was an expensive solution.

"We had to buy expensive specialist labels, as otherwise we had quality issues during spraypainting due to residue left by labels, so we decided to look into non-destructive methods of marking components during cutting. We couldn’t get anything from the machine tool vendor, as all its marking methods would still be visible after painting. After investigating further, we found an inkjet 'scribe' tool, but there were issues in driving it. However, after speaking with JETCAM, it was able to easily modify the postprocessor to also generate code for the inkjet," he told ISMR.
