# Rapid set-up for roll-forming

[TARİH: 01.02.2022 ISMR]

Profilmetall's XELLAR roll-forming machine, with RFID reader/writer for rapid tool set-up, was presented in Hall 3 at the Blechexpo exhibition in Stuttgart last October.

“The system features coded tools and operator guidance for quick production startup and reliable process setup. Above all, when roll-forming profiles with numerous variants, tool mix-up is avoided and the set-up process is greatly simplified," it told ISMR.

Tool systems coded with RFID chips make it possible to use the data stored for the respective roller set for operator guidance when setting up profiling systems. The control unit guides the operator through an interactive dialogue and shows him/her how and where to position the right tools within the system. Immediately after confirming that the work step has been completed correctly, the next tool can be inserted.

The Profilmetall Group is a specialist in roll-formed metal profiles and profiling systems. The corporate group combines the business areas of engineering, tooling and roll-forming system construction, as well as series production, under the umbrella of a group of companies with 100 employees.
