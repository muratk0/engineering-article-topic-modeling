# Tube bending with robots

[TARİH: 01.04.2020 ISMR]

ROBOTS HAVE ALREADY been used for some time as efficient and flexible bending machines to process tubes. The systems are constantly being improved. For the engineers at transfluid, this means firstly making the software user-friendly so that its bending systems can take isometric data and generate bending data without separate programming of the robot system.

transfluid has now designed the next step in the development of its range of tube bending robots. Online connection to CAD systems has always been possible, which greatly reduces set-up time. Another important aspect is simplifying the software connection for the robot programming capabilities of each customer.

"The latest generation of machines can process isometric data online. There are also positions stored in the control system, where the piece is picked up and dropped off. It is also now possible to retrieve the position for the necessary supports for long tubes. Because of this, new complex bending geometry can be programmed and bent quickly (30 minutes at the most). This includes set-up of the bending tools," transfluid told ISMR.

"Our bending cells, with two robots, bend long tubes at both ends. Tubes can be supplied with forming, hoses or connection systems. The preparation and cleaning of the tube becomes a lot easier.

It is much better to process straight tubes when the bending machine can bend at both ends. These benefits can be enjoyed when bending with one or two robots," it added.

With a set-up with two robots, it is possible to process tubes of up to 6,000mm. The two robots work in a synchronised way. Additional equipment, such as clamping or support devices, also synchronise with the processing robot. The robots recognize the component with a code, generate the bending sequence and can also choose between different radii and diameters. It is possible to work with a total of six different tube diameters or radii without having to change the dies, explained transfluid.

"A production cell with two robots can do more than bend a tube at both ends; each of the bending robots can also process different geometries. Both machines are working all the time and the system can be used efficiently and with a significantly higher output. The latest generation of our bending robots also offers safe handling: the grabbing coordinates on the tube for the pick-up from the magazine and for the drop-off can be retrieved from pre-programmed parameters. This means that the user does almost no programming of the bending sequence or the handling steps. The machine simply refers to pre-loaded data," added the manufacturer.

"Even tubes with long lengths, which are nearly impossible on conventional bending machines, can be processed without problems, as the long sections will not cause any collision problems. This is possible, because the last bend is done on the 'floating' tube, just before the drop-off. The entire system is operated by a bending machine control unit. The benefit is that it is possible to work with x, y and z coordinates, but also with lengths and bending angles, just like a standard bending machine."

Users do not need specialist knowledge of robot programming. To keep set-up times as short as possible, the robots have preprogrammed tool settings, including axes for the set-up position. This keeps set-up time short for the operator. See www.transfluid.de
