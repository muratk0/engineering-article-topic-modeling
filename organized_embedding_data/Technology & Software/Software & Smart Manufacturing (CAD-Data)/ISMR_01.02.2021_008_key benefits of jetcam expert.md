Technology-specific functionality has also allowed ASCO Power Technologies to save time. Tool Teach, in particular, has been instrumental in streamlining the process of applying punch tool hits to complex components.

"We adapt to whatever engineers request on the part with teach mode - we can teach a special tooling arrangement which will then be applied automatically on all parts with elements of the same geometry. JETCAM automatically cleans the file during import and then we'll auto-tool the part for each machine on which it can be processed, which means that it's ready to nest on any machine," commented James Hunley.

In 2014, the company upgraded its standard free form nesting to JETCAM's Free Form High-Performance Nesting module. This delivered, on average, a further 4% material saving using its time-based nesting algorithm.

## Fully dynamic nesting

Continuously looking for areas of improvement, ASCO Power Technologies identified that scheduled, fully dynamic nesting across all its machines would deliver further benefits. It reviewed MES systems, finally settling on Aquila DMM due to its tight integration with JETCAM Expert. In 2017, the company went live with DMM, with operators able to request nests on demand.

"Previously, operators might cherry-pick easier nests. Now, we are driven by data. DMM knows which parts to make and the next machine available, so it will send the parts for dynamic nesting to JETCAM, with NC code then quickly being ready. This ensures that the machines are always busy. The partnership between Aquila and JETCAM was a seamless fit," explained the company.

Real-world scenarios can also be managed, with complex parts (such as louvres) handled using static nests.

"DMM allows us to work outside the automated processes, if needed. It sees the order and knows that this requires an existing static JETCAM nest instead of a new dynamic one. Fully automating the nesting process freed up one person's job by 95% - now he just programs parts and oversees the DMM schedules," added James Hunley.

## Strong support is key

ASCO Power Technologies has continuously taken a maintenance contract from JETCAM, regularly seeing the benefit from features in new releases. Hunley has noted a continuous trend of improvement, especially with algorithms within the software.

"These have evolved over the years. Issues were uncommon to start with anyway, but now they are more of a rarity. The number of manual interactions is probably down by 80%," he explained.

With JETCAM, added Hunley, not only has the support requirement been significantly lower, but the quality of responses has set a new bar.

"I cannot say enough about what JETCAM and its distributor, NestOne, bring to the table in terms of response time. We don't need to call so often due to the level of automation..."

When ASCO Power Technologies first received JETCAM, training was provided by the machine tool vendor. Since then, new staff have been trained in-house by existing users, or with short online sessions with NestOne technical staff. ASCO Power Technologies also uses JETCAM's online 'University', which features hundreds of short videos (each detailing a specific feature).
