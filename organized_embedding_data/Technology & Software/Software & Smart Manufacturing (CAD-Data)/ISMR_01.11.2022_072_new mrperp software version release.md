# New MRP/ERP software version release

[TARİH: 01.11.2022 ISMR]

123 Insight Limited has announced the release of v10.15 of its core 123insight MRP/ ERP manufacturing software. The release contains new features and enhancements across all major areas of the software (including, commercial, stores, accounts, financials and CRM).

'Text library for despatch' builds on existing functionality to also allow users to either add standard text across despatch notes globally or build a comprehensive library of text snippets that can be added on a ‘per despatch' note basis.

With more stringent UK import/export controls, being able to identify the country of origin at any level is critical. In addition to recording country of origin at Part level, the country of origin can now be recorded at batch level in v10.15.

“Connectivity with other systems has also been improved, with enhancements to our optional Software Development Kit (SDK). This allows any system to safely communicate with 123insight, ensuring that links are not broken when either system is updated. New SDKs have been released covering purchasing, stores and project management," the software specialist told ISMR.

Simon Badger, Managing Director, 123 Insight Ltd, said; "V10.15 continues to deliver exciting new features and incremental improvements which, when combined, are greater than the sum of their parts. Many of these are requested by customers, and we can only continue to quickly deliver value through such releases due to our constant reinvestment back into product development.“

All 123insight customers can update to the latest version at no cost under the monthly subscription. A remote update service is available for £345.

The company was founded in 2000 and has been either nominated for or won dozens of awards. In 2021, 123 Insight Ltd. joined the Forterro group of companies.
