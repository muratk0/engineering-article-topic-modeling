# iRoll eXtreme control

[TARİH: 01.08.2021 ISMR]

Italian plate and angle roll manufacturer, DAVI, has just launched its new control system, iRoll eXtreme, for plate rolls. It features a new ergonomic console with a high-resolution touch-screen and live 3D interface.

"A smartphone-like, human-machine interface (HMI) experience will make programming easier than ever, thanks to integrated Artificial Intelligence functionality," DAVI told ISMR. "Smartphone-like environments can be tailored with high-definition widgets. Users can zoom in and zoom out for the required view of the machine and its accessories." New features introduced include 3D simulation for easy programming and live visualisation of the rolling process, Assisted Manual Mode (with Multi-Pass Aid and an accurate Apple-Shape Calculator) and Talk & Watch with Smart Glasses. Real-time fabrication fine-tuning can be made using high-res 3D simulation. A multi-pass aid generates an automated sequence for the selected number of passes. A re-rolling aid suggests the most appropriate apple-shaped geometry (ASME Tolerances Compliance System).

"With all these innovative new functionalities, as well as intuitive Phase Programming and a variety of templates available for programming cylinders, cones and custom shapes, the new iRoll eXtreme will enable users to maximize their throughput. The Real-Time Correction tool also allows users to easily and quickly modify the relevant segment of any shape," added DAVI.
