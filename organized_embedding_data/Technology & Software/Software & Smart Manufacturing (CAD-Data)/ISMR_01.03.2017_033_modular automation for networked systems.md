# Modular automation for networked systems

[TARİH: 01.03.2017 ISMR]

BAUMÜLLER INDIA PVT. Ltd. presented a 3-axis handling unit at IMTEX in Bangalore, India recently. The control unit of the handling unit can be integrated into existing, as well as new, production systems via a Euromap 67 interface or it can be operated as a self-contained system with its own control unit. It is also suitable for retro-fitting existing systems. The user interface of the control unit is simple and intuitive and the user can access the visualisation of the production data via smartphone or tablet if necessary.

From special technology modules to control technology and drives for robotics, Baumüller provides complete solutions for material handling and robotics applications. Visitors to the company's booth were shown different motor types, such as rotary, linear and disc motors, as well as the company's range of converters. Various control components, such as box PCs with HMIs and PLCs, completed the exhibited automation components.

Since last year, the multi-axis controller b maXX 5800 (suitable for robotics and handling applications) has complemented the Baumüller converter portfolio. The combination of six independently controllable axes into one controller enables significantly faster communication in the system than separate axis units. The decentralised servo drive, b maXX 2500, can be used across industries and for numerous industrial applications.
