# CAD/CAM nesting software

[TARİH: 01.06.2016 ISMR]

HYPERTHERM, a manufacturer of plasma, laser, and waterjet cutting systems, has announced a major version upgrade to its ProNest® advanced CAD/CAM nesting software for automated cutting. ProNest® 2017 contains a number of improvements that are designed, it told /SMR, to make customers more efficient and profitable. New features include manual nesting improvements (including drag array, anchor part to cursor and automatic bumping functionality for greater control and faster nesting); colour by part property and ProNest reports that show full colours in part images, making it easier to locate parts.

A re-designed drill machine interface for plasma or oxyfuel machines incorporates drilling, tapping and other spindle operations to tackle jobs directly in ProNest. Native 64-bit support allows ProNest to take advantage of the extra accessible memory available on a 64-bit CPU/Operating System.

"ProNest 2017 will deliver increased material savings, boost productivity, lower operating cost and improve part quality," said Derek Weston, product marketing manager for Hypertherm CAD/CAM software products. "In addition, ProNest 2017 contains more embedded cut process expertise in the NC code than any other software, allowing our customers to leverage patented technologies like True Hole®, True Bevel™ and Rapid Part™."

Hypertherm nesting software for cutting in production environments, formerly named TurboNest®, is now called ProNest LT. Hypertherm nesting software for cutting in job shop environments, formerly NestMaster™, is now ProNest LTS. ProNest LT and LTS contain many of the features found in ProNest 2017. Users with an active software subscription can upgrade to the new version of their respective product at no additional charge and continue to receive unlimited technical support.

Hypertherm is also now shipping its PowerDredge™ waterjet abrasive removal unit to customers around the world. First unveiled at the 2015 FABTECH show, the unit is designed to increase waterjet productivity and profitability by automating costly abrasive clean-outs. Instead of relying on manual labour to shovel or suck out used abrasive, the PowerDredge automatically collects and deposits abrasive into a large bag for quick recycling or disposal.
