# Sheet metal inspection

[TARİH: 01.04.2016 ISMR]

AT THIS YEAR’S CONTROL 2016 SHOW in the UK (Hall 3, Stand 3330), GOM will be presenting the new ATOS ScanBox Series 7 and 8 for the inspection of large and heavy sheet metal parts e.g. side panels or complete car bodies, in press shops and body plants. In conjunction with the Auto Teaching function, the ATOS ScanBox is a precise and high-speed measuring machine for a full-field component analysis including hemmed edges, hole patterns and trimmed edges.

With the ARAMIS 3D Camera, GOM is presenting a new sensor for materials and components testing. For the first time, the new ARAMIS system is combining point-based and full-field deformation measurement in a single system. This makes ARAMIS a standard measurement system for industrial applications in materials and components testing.

GOM Inspect is used as evaluation software for 3D measuring data including 3D inspection and STL mesh processing, which enables an independent evaluation of measuring results. By importing native CT data, the GOM Inspect software now also enables a straightforward evaluation of measurement data derived from another non-contact measurement process. It is possible to input data from computer tomographs such as from Wenzel, Werth, GE, Zeiss etc.

GOM Correlate is free software for digital image correlation (DIC) which allows 2D evaluations of digital image series and movie files from conventional, uncalibrated single cameras, including complete evaluations and reports. The software is also used as a viewer for measuring data from GOM’s ARAMIS 3D Camera stereo camera system. See www.gom.com
