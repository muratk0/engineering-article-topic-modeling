# MRP/ERP manufacturing software v23.1

[TARİH: 01.08.2023 ISMR]

In its largest release in over a decade, 123 Insight Limited announced the release of v23.1 of its core 123insight MRP/ERP manufacturing software this April. The release contains an entirely updated user interface and major new features across all major areas of the software including commercial, stores, accounts, financials and CRM.

"The user interface has been completely overhauled. It retains and enhances the original functionality and workflow, now including features such as a new lefthand tabbed interface. Numerous feature enhancements have been included across the software, such as having greater control over which components are issued to a works order using 'backflushing'. You can now control parts, such as highly traceable components, to ensure they must be manually issued whilst allowing others to be backflushed using the global setting," explained the software manufacturer.

Documents can now be associated against a batch, not just a part, which is useful for items such as Supplier CofC and test results. Improvements have been made to two-stage and three-stage despatch options, allowing users to add new lines to an existing despatch note. This will enable them to build up a despatch over time and print a single despatch note. Other notable features include better cloud hosting options and a new reports designer.

"All 123insight customers can upgrade to the latest version at no cost under the monthly subscription. We also offer a remote upgrade service for £345," added 123 Insight Ltd.

The company was founded in 2000 and has been either nominated for, or has won, dozens of awards. In 2021, 123 Insight Ltd. joined the Forterro group of companies.
