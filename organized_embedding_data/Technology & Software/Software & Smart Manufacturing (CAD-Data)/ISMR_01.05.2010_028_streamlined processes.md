# STREAMLINED PROCESSES

[TARİH: 01.05.2010 ISMR]

CAD/CAM is the acronym for computer-aided design/computer-aided manufacturing and denotes computer systems that are used to design and manufacture products. The term CAD/CAM implies that an engineer can use the system both for designing a product and for controlling manufacturing processes. For example, once a design has been produced with the CAD component, the design itself can control the machines that construct the part.

CAD/CAM solutions can save sheet metal users material, programming and set-up times as well as cutting costs and improving productivity. ISMR highlights some of the latest new CAD/CAM software functionality in today's markets.

## IMPROVED PRODUCTIVITY

In the latest version of some software releases, assembly parts can be analysed for common design problems before manufacturing release. These include missing or incorrect material properties, unmapped materials and missing sheet metal styles. Problem parts are highlighted in the assembly list allowing them to be corrected before continuing with the release process. This streamlines the manufacturing release process and exposes persistent design issues requiring further scrutiny.

Above: ZWCAD 2009 version

Increased functionality, in the form of numerous enhancements to existing features as well as new technology, has instant effects on overall productivity. Some manufacturer interfaces can present commands using a simplified, structured interface that makes the software easier to learn and use. The result is simple: more can be accomplished in less time.

One of the enhanced features available now is the ability to create, track and nest on irregular-shaped (non-rectangular) sheets or plates. The software will create a crop cut to separate the unused portion of a nested sheet. This sheet remnant, regardless of shape, is then placed into inventory for future nesting consideration. A sheet remnant can be assigned to a subsequent nest job by the user or the software can automatically select a sheet remnant when it is determined to deliver the greatest material utilization. In other words, helping users to reduce scrap levels by incorporating remnant sheets that might not otherwise be considered for production.

There is continued pressure on optimal material usage and CAD/CAM manufacturers have increased functionality to respond to these requirements. One told ISMR:-

“Manufacturers can significantly reduce inventory and increase material utilisation. Whether designing or importing models, some software versions can work with multiple formats of 2D and 3D CAD data. In 3D, the introduction of the latest ACIS Kernel offers greater stability and performance when loading Catia and Parasolid files."

More automated functions to control part and part picker movements are now included in some new software releases. For example, a strategy can be set to define the order in removing the part or scrap operation. A new 'constrain' option can allow users to control the movements of the part and part picker during unloading functions for their machines, resulting in a more controlled environment.

The ability to integrate with enterprise management software is an added bonus for users as is a facility to manage parts and metal storage, sorted according to different criteria and through open databases. This feature also enables users to calculate time and cost per piece and per sheet which gives them greater control over budgets and the workloads of different machines to better improve resources and thus increase productivity.

Parts placed into a library include the necessary manufacturing data from the Inventor model, including material properties, revision information, and even routing details. As soon as the parts are placed into the library they are available for single part and nest processing on CNC punching and cutting machines.

## CAD/CAM solutions can save sheet metal users material, programming and set-up times as well as cutting costs and improving productivity

## HIGH PERFORMANCE NESTING

GT Metal Products, based in Alberta, Canada, provides custom fabrication services using two Mazak STX510 MklI 2.5kW lasers. It had previously been running two CAM systems to drive the lasers, but experienced problems that made it consider alternative solutions. New CAD/CAM software to programme its Mazak CNC laser gave the company a return on investment of two months as it halved its programming time, reduced machine runtime by 20% and material wastage by 25%.

Dustin Sim, Production Manager, said; “Previously we could only specify one cut condition per thickness, which gave us quality issues. Also, we were looking to find a faster way to nest parts and reduce material waste."

A High Performance Nesting module in the software allows two programmers to design parts and for one machine to be used for generating highly optimised nests. Programming time was halved, as processes took much less time than the previous systems due to many being automated. Once profiling information is applied to each part, it is immediately available for each machine, with any updates reflected automatically on any nests.

Above: A Radan 3D modelled part

Nesting time itself saw a 90% reduction, as users queue up all parts to be nested for a given material and thickness, specify an amount of time that the nester can run for (which can be overnight to allow the system to consider the most optimized nesting options) and generating NC code. Machine cycle time also saw a 20% improvement due to optimized lead-ins, common line cutting, path optimization and finishing cut sequences.

Finally, material utilization saw a 25% improvement not only because of the optimized nests from High Performance Nesting but also the ability to store and re-use remnant sheets efficiently.

The 12th annual SolidWorks World conference 2010 brought together designers, engineers and partners to discuss ideas, trends and the technology shaping the future of product design. CAD/CAM software on display used the advanced design analysis capabilities of SolidWorks to provide users with a smooth transition from a 3D assembly to NC code for laser, plasma, oxyfuel, waterjet, router and punching, all without leaving the SolidWorks interface.

CAD/CAM solutions can save material, programming and set-up times as well as cutting costs and streamlining operations – in today's competitive markets, where margins can be squeezed tightly, they can make a real difference to sheet metal productivity. ISMR
