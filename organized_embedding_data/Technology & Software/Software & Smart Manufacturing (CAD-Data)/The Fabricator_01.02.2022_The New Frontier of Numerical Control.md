# The New Frontier of Numerical Control

[TARİH: 01.02.2022 The Fabricator]

The Fabricator’s Technology Showcase Special Advertising Section

MG and its partner Delsy, a company founded in 1979 with a focus on software and numerical controls, offer high-quality products developed through continuous innovation and their ability to think out of the ordinary. MG’s philosophy is to customize its products as if they were a tailor-made suit; this process naturally takes time but results in products suitable for any required application.

Two new creations have been released, the result of long and meticulous technical and engineering work. The first is the NC Easy Command. This numerical control replaces the previous NC Nexus, which could archive up to 900 programs. In response to customer requests, MG’s engineers redesigned the NC Nexus functions, starting with the number of programs, to achieve 9,999—almost infinite.

Moreover, the NC Easy Command offers integrated alarm management and warnings to guide the user. These features are easily accessible, even for operators without extensive experience. Version 4.0 has the same features as the basic version, but with enhanced functionality. For instance, when connected to the company network, it generates a file in .csv text format with all the available data that can be interrogated by a company server, thus achieving a full integration via OPC-UA communication protocol. It is also possible to connect to the operator panel remotely on a PC, tablet, or smartphone connected to the same local network.

While the NC Easy Command is the big news of the MG expansion season, the Touch Command CNC series also continues the company’s drive toward innovation. The system has an easy-touse man-machine interface, a powerful digital motor, and a closed-loop system that constantly controls the position of the axes and their interpolations. This type of numerical control is also easy to use, but it is usually recommended for high-volume production or for bending complex shapes, such as variable radii, ovals, and elliptical shapes.

New models being launched on the market are the CNC Touch Command EVO 4.0, the Touch Command EVO 4.0 Plug-in, and the Touch Command EVO PLUS. The first one is a step forward compared to the already existing Touch Command EVO, as it is equipped with a CNC connection with Ethernet cable directly on the electrical panel, as well as the integrated We App, visible within the local network, that allows the user to view the machine status, order management, executed programs, production charts, and maintenance. Furthermore, sensors have been added to check the machine status in real time, such as oil filter or oil temperatures. The last and most advanced version, the Touch Command EVO PLUS, has a bigger digital touchscreen compared to the basic version (21.5 in. instead of the usual 15 in.), along with the EPG (external program generator). This optional software can be installed on Windows computers to create programs directly from the office and export them to a USB key.
