# Alma GmbH

[TARİH: 01.09.2022 ISMR]

www.almacam.com

For over 40 years, Alma's software solutions have helped to optimise material consumption and the potential of machines and robots. Alma will present the latest features of its new-generation Almacam software suite for 2D/3D cutting, sheet metalworking and mechanical welding (CAM for laser/plasma/waterjet cutting; punching-nibbling; routing; tube and profile cutting; offline programming of welding robots; sheet metal quoting; production management; ERP integration etc.).

Almacam is now available as a SaaS solution, providing a flexible and all-inclusive service to program machines and draw up quotes, enabling manufacturers to deal with a wide range of activities. One focus will be on Nest&Cut, a web application that nests parts and generates the NC code for machines. Alma's Cloud software components for cutting optimisation will also be on display.
