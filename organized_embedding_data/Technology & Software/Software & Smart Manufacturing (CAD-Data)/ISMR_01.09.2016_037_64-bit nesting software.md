# 64-bit nesting software

[TARİH: 01.09.2016 ISMR]

IN ITS VERSION for 64-bit microprocessors, new Lantek Expert CAD/CAM software is designed to provide increased memory capacity, higher performance and improved security. This specific version of the software, along with the version for 32-bit microprocessors, will be included in the launch of the Global Release 2017. Among other advances, the 64- bit version is estimated to deliver an improvement of up to 50% in the speed of some of the calculation processes.

“Lantek's philosophy is to always be one step ahead in its sector and the adaption of its software to 64-bit-microprocessors is a significant improvement, which will provide increased efficacy for all the functionality in its solutions. This is yet another move towards industry 4.0”, explained Asier Ortiz, Chief Techology Officer (CTO) at Lantek.

X64 processors have double the number of general purpose registers and SSE than x86 processors. The registers can operate with 64-bit integers. The output of the new Lantek Expert for 64-bit, which is an application that has many calculations using complex algorithms, will be improved considerably with the use of these extra registers. Another significant advantage is increased security in the execution of the code and its installation. An example of this new feature is the protection offered for buffer overflows which ensures the correct and secure execution of the code.
