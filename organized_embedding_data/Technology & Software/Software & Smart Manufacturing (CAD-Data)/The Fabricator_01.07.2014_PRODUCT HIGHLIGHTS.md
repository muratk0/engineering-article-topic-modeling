Vision-guided technology contributes to faster robotics programming, setup

ABB Robotics has introduced Integrated Vision, a smart camera system for vision-guided robotics applications. Using 2-D vision guidance, the system allows manufacturers to track products, improve quality and supply chain management, troubleshoot lines and process, and expand their use of robotic automation, according to the company.

Powered by Cognex, the system features the PatMax® algorithm for advanced part location. The result is robust inspection, defect detection, guidance, alignment, and measurement, the manufacturer reports.

The RobotStudio PC-based programming tool provides the platform for creating vision tasks. Operators can select features, set parameters, and operate under real-world conditions from a library of common vision applications. The smart camera offers a variety of built-in communication protocols that interface directly with the robot for faster programming and setup.

Laser machine cuts large workpieces with reduced electrical consumption

Mitsubishi Laser has introduced the RX series laser system, designed as a cost-effective option for cutting large workpieces. The ML4020 RX machine is built to handle workpieces up to 13 by 6.5 ft. Resonators are available in 45 and 60CF-R.

The Blow Pierce feature can reduce piercing times in mild steel up to 80 percent, the company reports. The new FAB control feature expands the focal range of the beam, allowing more stability across the cutting area. New Motion Cut technology allows the laser to move through thin materials at high speeds.

To keep costs down, the ECO Mode reduces electrical consumption, while resonator cleanliness puts less stress on optical parts and helps elongate optical life, states the manufacturer. Patented resonators can help reduce assist gas consumption by up to 30 percent.

Simple true nesting allows for quick, on-site response times, and a double-cut function allows cutting of protected sheet metal. The offcut cutting function cuts remnants from the nested sheet for increased material yield rate.

Press brakes include new options

Bystronic offers its Xpert and Xcite press brake series equipped with the ByVision bending control. The control, which includes a database of material bend angles and bend allowances, uses a 22-in. HD touchscreen to display 3-D part animations and software-driven menu selections. Bending profiles can be imported or drawn directly on the touchscreen and then automatically converted to a bending program with proper bending sequences and tool selections.

The new Voice Control option enables operators to use voice commands, via a headset, for typical manual operator functions. Optical Bend Guiding guides operators through all bending applications. LEDs indicate the correct position of the toolstations, backgauges, and bending sequences.

The new RF-A and XPT tooling and clamping systems provide users with front-loading, lightweight segmented tools. PartID laser-etched part code can be registered by an optional scanner unit at the brake, and the desired bending program can be loaded automatically.

Machine inserts four different fasteners in same part handling

Phillips Corp. offers the Haeger 824 MSP insertion machine. Its manual four-station turret allows insertion of four different fasteners in the same part handling. The PLC touchscreen allows the operator to set force, dwell, up-travel, batch counter, and TPS for each station.

The hydraulic machine delivers 8 tons of ram force, with a 24-in. throat depth. Its positive-stop cylinder is designed for use with soft materials such as aluminum so that fasteners can be inserted without crushing or deforming the part.

The patented safety system is effective at any point in the ram stroke, regardless of the tooling length, and it requires no operator setup. The variable dwell timer is available for inserting fasteners into stainless steel.

Magnetic drills adhere to material as thin as 0.0625 in.

Alfra USA offers the P line of magnetic drills. The patented magnetic base technology can adhere to materials as thin as 0.0625 in. Residual magnetism enables the operator to position the drill before engaging the magnet.

The patented motor control system eliminates the need for circuit boards. All controls are in the motor. A drill performance LED indicator panel tells the operator the RPM, downward pressure in pounds, and hours on drill during operation.

By turning the motor control cap, the operator can achieve infinitely variable RPM for right and left operation. It is suitable for TCT and HSS cutters in various sizes. The patented slide with self-adjusting tension keeps the motor where the operator wants it. Additional height adjustment converts the machine to a magnetic jobber drill.

Unwind system keeps stretch hood corners thick

Lachenmeier has introduced its patented Unwind System as standard on its stretch hood machine. The system gathers the film at the corners and unwinds it as the film is placed over the load. The process nearly eliminates thin and fragile film on load corners—a feature that is important for loads with sharp edges.

According to the company, the system keeps film corners about 30 percent thicker than other stretch hood systems. Users can incorporate lighter film gauges without compromising load integrity.

The system provides five-sided waterproof protection, making it suitable for outdoor storage and shipping on flatbed trucks.
