# Nesting made easy

[TARİH: 01.01.2015 ISMR]

LOGOPRESS CORP., Besancon, France, along with its North American distributor and technical centre, Accurate Die Design, Inc., of New Berlin, Wisconsin has just released a new rapid and easy-to-use product that is fully integrated inside SolidWorks, called Logopress3 NESTING.

The software is intended for many kinds of parts and industries and includes options such as the ability to set a sheet size to nest on or set just the width, angular control and constraint of parts, the option to nest into openings, automatic report generation etc.

Logopress3 NESTING starts with either a multi-body part file (either created with SolidWorks or imported from a different CAD system) or with individual part files that are in an assembly. After setting some logical parameters that enable flexibility, it will quickly nest the parts to the options that the user sets. No formal training is necessary.

Logopress Corp, which celebrated its 25th anniversary last year, develops die design software for the tool and die industry as well as flattening and blank prediction software for many kinds of parts and industries. Logopress3 solutions are currently used in over 30 countries around the world.”
