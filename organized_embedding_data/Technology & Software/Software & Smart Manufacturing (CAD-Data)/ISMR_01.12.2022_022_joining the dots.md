# Joining the dots

[TARİH: 01.01.2022 ISMR]

AESUB provides reference points for universal 3D scanning which are system-independent. Reference points that facilitate the acquisition of 3D objects with optical scanners are now available quickly and independently of the system.

"Up until now, self-adhesive reference points were almost exclusively available as measuring accessories from the device manufacturers. As a manufacturer of sublimating scanning sprays, we can offer the points very quickly and cost-effectively using our widespread partner network. AESUB dots are available for various scanning technologies in all common diameters," commented the manufacturer.

The reference points can be placed on the object to be measured both before and after spraying with the AESUB scanning spray. The reference points adhere to the spray coating and can be easily removed again. "Using our scanning spray and dots make scanning glossy and reflective surfaces much easier and more efficient," AESUB added.
