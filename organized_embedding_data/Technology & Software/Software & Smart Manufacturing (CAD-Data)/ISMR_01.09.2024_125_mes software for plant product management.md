# MES software for plant product management

[TARİH: 01.09.2024 ISMR]

BLM GROUP USA has announced the rebranding and revamping of its ProTube Enterprise Manufacturing Execution System (MES) software as "Prometheus", now extending beyond the company's tube laser machines by adding compatibility with its line of sheet lasers.

"The implementation of Prometheus allows BLM GROUP tube and sheet laser machines to be integrated seamlessly with all machines on the floor. It is also fully compatible with any customer software and ERP systems that the machine may be using. This is a significant advance to support production floor managers by streamlining job management for all machines on the floor into a single planning system with a single monitoring dashboard," explained the manufacturer.

"Fabrication machine manufacturers typically create custom software for each individual machine to streamline the user experience, but this diversity in software can increase complexity for floor managers," explained Kenny Criger, Applications Manager, BLM GROUP USA.

"Prometheus aims to simplify the process by creating a single MES interface for tube laser, sheet laser, five-axis tube benders and cold saws in a single application—adding the most value to customers who are operating multiple BLM GROUP machines.

Prometheus will work in unison with any ERP software being used. Floor managers can control the workflow seamlessly: blocking off scheduling on machines that are undergoing maintenance and sending the jobs to other running machines from one application, on one screen," he added.

The software evolution to Prometheus was conceptualised to deliver greater ease of use, a fast and direct interface, as well as optimised synergy between software and machines.

Real data production at a glance

"In addition, the inclusion of a live efficiency analysis system allows estimates based on real statistical data to be provided for new job orders, ensuring accurate timeframes and cost estimates for production," concluded the company.

BLM GROUP is a global specialist in tube and sheet metal machine solutions. Its product portfolio includes tube lasers; five-axis lasers; sheet lasers; press brakes; tube benders; wirebenders; end-formers and cold saws.
