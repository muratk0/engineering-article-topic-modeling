# Cobots at Robotics & Automation

[TARİH: 01.09.2019 ISMR]

DUGARD MACHINE TOOLS has announced that it will be exhibiting at the Robotics & Automation exhibition at the Ricoh Arena in Coventry from 29-30 October 2019. The UK's largest dedicated robotics and automation event will be a launch-pad for the Brighton Company to introduce its new range of Hanwha HCR collaborative automation solutions.

Dugard's Hanwha HCR Cobots, launched in 2018, gave the company a platform for automating machine tools. On stand 412 at the exhibition, Dugard Machine Tools will be demonstrating the HCR-5 model from the Hanwha range that caters for loads up to 5kg.

"With a reach of 915mm, the Hanwha HCR Cobot can be easily moved around the workshop via a trolley that is also available as an optional extra. Each system in the extensive range includes one arm, one pendant and one case. However, one case can actually run two robots, so the second robot system will always prove more cost-effective," it explained.

"The user-friendly and flexible system has already been installed at a number of UK machine shops with phenomenal success; many of the new customers are already looking to install additional Cobots."

Siavash Baghaei, technical manager for Dugard Machine Tools, said: "The robots are so easy to program, you don't need another skilled individual to use or program the system. Another advantage of this Hanwha HCR robot is the ability to push the arm back, once it has reached its stop position. This is unlike other systems that lock in a specified destination. So, if your hand ever gets trapped between the robot and the machine or a wall it can be moved and this is recognised as a positive safety feature."

The HCR Series incorporates collision detection, joint rotation and speed limits, a virtual safety fence and a control system. An additional benefit on the Hanwha is the 'path teaching' function which is an optional extra on alternate systems. This robot, unlike standard Linux-based systems, is Windows-based. This allows users to 'break into' the software and reprogram or add features for universities and educational establishments.
