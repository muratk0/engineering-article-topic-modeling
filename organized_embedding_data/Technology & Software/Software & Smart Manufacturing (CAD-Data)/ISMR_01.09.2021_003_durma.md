## SOLUTION MANAGEMENT SYSTEM DURMA SUPERVISOR

Supervisor is the central control software unit which was developed by Durma. It distributes and controls the workflows of all units (different machine groups such as laser, punch, panel bender, and loading/unloading systems, pick & place systems, etc.) working integrated with each other in the line system from a single center.
