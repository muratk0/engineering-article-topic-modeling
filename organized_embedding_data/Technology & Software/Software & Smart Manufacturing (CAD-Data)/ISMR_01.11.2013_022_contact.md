## Quotation software for sheet metal parts

ALMA has expanded its CAM software suite for nesting and sheet metal machining to include almaQuote quotation software for sheet metal parts. This is intended for subcontractors who must rapidly respond to requests for quotation as well as manufacturers looking for customised functions or applications tailored for very specific needs. It is a stand-alone product based on the new almaCAM platform that will eventually unify all the CAM software products from Alma.

“Via an intuitive graphical user interface, almaQuote users can quickly estimate the cost of part manufacturing from the part characteristics. They can also precisely calculate the cost of all operations required for part manufacturing, using the actual part geometry (dxf) and the number of sheets to be used calculated from true shape nesting optimisation. It is possible to estimate the manufacturing cost for single parts or part sets,” Alma told ISMR.

The software can create new operations of any type, defining or modifying parameters or formulae for cost calculations as well as editing quotes and output reports. The workflow can also be customised by including, for example, an additional validation step. Multiple user rights can also be managed.

The almaQuote software as well as the entire Alma CAM software suite for 2D/3D cutting, punching, bending and robot welding was demonstrated on Alma’s booth at Blechexpo. See www.almacam.com
