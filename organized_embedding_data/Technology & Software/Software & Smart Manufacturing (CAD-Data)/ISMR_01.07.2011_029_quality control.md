# QUALITY CONTROL

[TARİH: 01.07.2011 ISMR]

HARDNESS TESTING is one of the most common materials test, used by virtually every industry.

Buehler, a manufacturer of scientific equipment and supplies for material preparation and analysis, has launched the new MicroMet 6000 Series hardness testers.

“The series has been completely re-engineered and combines an intuitive user interface so that operators become immediately productive. The MicroMet 6000 Series system is completely integrated, and the ability to access any setting in three clicks or less provides for a new class in usability and ease-of-use,” said the company.

From the USB data port located on the front of the tester, users can export data to a flash memory drive in common formats. Additionally, a USB on the back of the MicroMet 6000 enables integration with Buehler’s OmniMet MHT software for automated testing solutions. New, custom-design optics coupled with LED illumination deliver sharp and clear images of test surfaces. Used for quality control and metallurgical research with dead-weight loads from 0.01 to 1.0kg, the MicroMet 6000 also features a 2kg option. Calibration certificates for the tester, testblocks (provided) and indenter conform to all internationally recognized micro-hardness testing standards. See www.imipr.com
