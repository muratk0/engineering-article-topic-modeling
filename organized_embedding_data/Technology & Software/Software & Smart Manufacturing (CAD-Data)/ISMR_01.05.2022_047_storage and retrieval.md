# Storage and retrieval

[TARİH: 01.05.2022 ISMR]

Supplying storage and retrieval solution for the engineering sector since 1963, Polstore Storage Systems manufactures and designs CNC tool storage and transport products. The range includes CNC toolholders; CNC stand and trolleys; roller shutter cabinets; storage cabinets as well as racking and shelving. Built as a modular storage solution, each component is designed around the customer's working practices. Every inch of the workspace can be optimised, the company told ISMR.

Whether opening a new workshop or renovating an existing workspace, the company can show examples of workshop fit-outs.

“Every storage challenge is individual and is treated as such. A foam shadow board system is a cost-effective way for storing tools, fixtures and high-value assets. Adding bold colours to the shadow board can give a visual clue to a user when an item is missing. All foams are designed inhouse and manufactured from plastazote, a material which is inert, chemically resistant and hard-wearing," said the company.

"Our project sales team can help to design storage systems, working with customers to create efficiency; enhance display and accessibility; reduce waste; lower costs; improve attitudes and motivate people within the workplace," it added. ■
