# The latest CADMAN® software suite includes various enhancements for CADMAN-JOB (Manufacturing Execution System); CADMAN-SDI (Smart Drawing Importer); CADMAN-P (punching) and CADMAN-L (laser cutting) designed to improve process flow.

[TARİH: 01.08.2022 ISMR]

CADMAN is now able to integrate foreign operations such as tapping, deburring and grinding. These can be tracked and traced in the production process for realtime transparency. CADMAN manages the complete sheet metal production process with no need for an ERP system.

“This functionality makes CADMAN a practical solution for sheet metalworking businesses of all sizes, including companies who don't have an ERP system," added LVD.

Enhancements also include the ability to create an execution plan and add unplanned operations during production using CADMAN-JOB; “drag and drop" importation of files and the ability to "expand parts," in CADMAN-P and CADMAN-L, among other new updates.
