# AutoForm-DieDesignerPlus

[TARİH: 01.10.2023 ISMR]

AutoForm Engineering GmbH, a supplier of software solutions for stamping and BiW assembly processes, is introducing its newly developed software, AutoForm-DieDesignerPlus. With this software, users can create and compensate high-quality CAD surfaces within the AutoForm Forming suite. The integration of AutoForm-DieDesignerPlus within the AutoForm software environment ensures data continuity during process design.

"The creation and compensation of highquality CAD surfaces as preparation for manufacturing has typically been carried out using external CAD software. This software requires user familiarity with its application and the tedious multiple importing and exporting of data from and to CAE software as well as the creation and potential integration of additional external documentation," explained AutoForm.

"However, AutoForm-DieDesignerPlus provides a set of geometry creation features within the easy-to-use AutoForm user interface. With this software, users can quickly create final die-face geometry without requiring additional CAD software. This new option is tailored to the needs of engineers responsible for final CAD-quality surfaces and eliminates the need to import and export data, resulting in a higher level of efficiency and ensuring data continuity," it continued.

"AutoForm-DieDesignerPlus is best applied during the process design phase to facilitate the creation of high-quality CAD surfaces. These surfaces are required for the final validation simulations and compensation of die surfaces, which will be exported afterwards for use in die manufacturing. A new level of efficiency in the process design phase is achieved because of the seamless data flow and the use of process plan information created earlier (in the concept development stage)," added Dr. Markus Thomma, CMO of the AutoForm Group.

With AutoForm-DieDesignerPlus, he summarised, users can create high-quality CAD surfaces for manufacturing within the AutoForm software environment. This software, with its new features and capabilities, is designed to ensure the seamless flow of data and facilitate daily work in process design departments.

AutoForm offers solutions for sheet-metal forming and BiW assembly process. With over 400 employees dedicated to this field, it is a leading provider of software for product manufacturability, tool and material cost calculation, die-face design and virtual stamping as well as BiW assembly process optimisation.

Besides its headquarters in Switzerland, AutoForm has offices in Germany; The Netherlands; France; Spain; Italy; Czech Republic; Sweden; USA; Mexico; Brazil; India; China; Japan and Korea. It is also present through its agents in more than ten other countries.
