# Time and project management tool

[TARİH: 01.03.2020 ISMR]

LOGOPRESS, a long-time SOLIDWORKS® software partner, has announced the launch of a new add-in product, called SOLIDReporter™, which has been developed for all SOLIDWORKS users. SOLIDReporter™ is an easy-to-use add-in designed to work seamlessly within SOLIDWORKS to automatically record, monitor and manage time, tasks and projects.

“SOLIDReporter will automatically record time spent working on parts, assemblies or drawings while automatically switching between projects based upon criteria defined by the user. It also provides the flexibility of creating custom tasks to keep track of time spent while working outside SOLIDWORKS, whether it is time spent in meetings, on breaks, in the shop etc. SOLIDReporter helps the user and the manager to monitor their projects in real-time. It also allows the user and the manager to generate analytical reports by project, task or time period. It is designed to be forgotten, without forgetting what was worked on in SOLIDWORKS," said Logopress.

SOLIDReporter automatically stops allocating time to a project, based on a user defined period of inactivity in SOLIDWORKS. The user can also add notes such as reminders, ideas and questions to the currently active project to follow up on them later. In addition, a time budget can be set for each individual project. SOLIDReporter then monitors the amount of the budgeted time used, providing alerts at project milestones.

Since 1989, Logopress (headquartered in Besançon, France) has been primarily focused on the development of die design software for the tool & die and metal stamping industries, as well as related flattening software for various applications. Logopress is a specialist in die design software and its Logopress3 products have achieved SOLIDWORKS Certified Gold Partner status.
