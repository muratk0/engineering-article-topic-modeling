# Loss-free conversion of 3D/CAD data for a smooth workflow

[TARİH: 01.03.2024 ISMR]

Software developer, CT CoreTechnologie, has further developed its CAD converter, 3D_Evolution, and is now introducing native interfaces for reading Solidedge and writing Nx and Solidworks files. The Franco-German software pioneer is presenting 3D_Evolution for the seamless integration of 3D/CAD systems and downstream applications. Using optimised memory management, the new software version has an improved processing speed and enables optimised processing of very large models.

"The CAD converter offers engineers and designers a powerful solution for the precise and efficient conversion of CAD data into various formats. The new interfaces fulfil the current requirements of the industry.

The software, with its latest improvements, offers substantial benefits for users who heavily depend on 3D modelling and design, utilising 3D models as their primary source of information, for the development of complex products," explained the software specialist.

Above: The new 3D_Evolution software. Image: CoreTechnologie GmbH.

The new version of 3D_Evolution supports a wide range of CAD formats, such as Catia; Nx; Creo; Solidworks; Solidedge; Inventor; Step and Jt, to facilitate smooth interoperability between different systems and collaboration in development environments with different CAD systems. The geometry kernel created specifically for data conversion is designed to enable accuracy and reliability in the translation of CAD data and ensures that even complicated design details are retained without gaps during the conversion process.

"With its intuitive user interface, the CAD converter simplifies complex and time-consuming conversion tasks. This enables the user to navigate easily through the software as well as an optimised, fully automated workflow. In modern product development environments, in particular, large volumes of data are exchanged between different 3D software solutions in the shortest possible time to integrate the various development partners. Data quality plays a major role here, which 3D_Evolution generates using automatic data healing functions," concluded CT CoreTechnologie.■
