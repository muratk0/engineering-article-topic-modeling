# An eye on fixtures

[TARİH: 01.08.2022 ISMR]

Rivit Srl's CONTROLRIV4.0 is a monitoring system for blind rivets and rivet nuts, which helps users to plan different placing operations, monitor the work process and easily analyse the resulting data.

“The system is connected to the riveting tools and, depending upon the working methods and predetermined settings made by the operator, the work of one or more tools can be monitored in real-time to avoid mistakes and deactivations. The results are improved productivity, higher standards of work and reduced levels of waste," explained the Italian manufacturer.

CONTROLRIV4.0 is designed in modules, with a Primary and 11 Replica so that up to 12 workstations can be managed simultaneously. The Primary, with a touch-screen display and userfriendly software, can interact with a PC and a PLC. It downloads all work data on portable storage drives.

The Replica, more compact than the Primary, manages the operation of the riveting tool by indicating its status on integrated LEDs. Although all the work is managed by the Primary, the Replica in certain configurations can also communicate with the PLC independently.

“Assembly operation monitoring is done by study of the curves, piece and batch counters as well as work lists. Monitoring is supported by stored batch data, all check activities, implemented work lists and by recorded curves. For working phases, visual and sound alerts have been designed to flag correct or incorrect applications (i.e. lack of air, in the latter case). In addition, for a clearer and more visible reference, a three-colour luminous tower with alarm siren is also available," added Rivit Srl.

Every single unit features a pneumatic valve that turns compressed air on and off to safely secure the system, distinguish working phases from configuration ones and prevent further errors in the event of an incorrect application result.

CONTROLRIV4.0 works with tools for rivet nuts RIV938, RIV939, RIV949 and RIV916B, and with tools for blind rivets RIV503, RIV504, RIV508, RIV511B and RIV300.
