# Automated path to unmanned production

[TARİH: 01.09.2022 ISMR]

At the AMB exhibition in Stuttgart from 13-17 September 2022, Dutch robot-cell manufacturer Cellro BV will be presenting its latest robot cells.

"Thanks to intelligent functions such as 'job verification', unmanned production is becoming more predictable than ever. We aim to make the step to unmanned production increasingly smaller for machining companies," it told ISMR.

"We want to enable machining companies to respond quickly and flexibly to customer requests. The automation of high-mix, low-volume production has, in addition to large batches, always been a spearhead. We have now automated the production of these complex order flows for numerous customers. At the AMB exhibition, we will be demonstrating the smart functionality that makes this possible," it added.

New features include 'job verification'. The control system automatically checks whether machines, materials and all other supplies are available for the jobs to be performed. This enables the operator to avoid interruptions in automated production.

Cellro has also developed a roadmap for manufacturers that want to start automating their production.
