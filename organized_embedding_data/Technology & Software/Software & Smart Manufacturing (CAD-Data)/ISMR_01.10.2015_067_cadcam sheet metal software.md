# CAD/CAM sheet metal software

[TARİH: 01.10.2015 ISMR]

ALMA HAS specialised for 35 years in the development of CAD/CAM software for automatic nesting, 2D/3D cutting, sheet metal working and robotics. It has launched almaCAM, a new environment housing for Alma’s CAM software modules designed for 2D cutting by following contours (laser, plasma, oxy-cutting, waterjet), punching-nibbling, routing, 3D cutting, tubes/profile cutting and robot welding.

It is also a platform designed for hosting and developing new CAM or CAM-related applications such as quote creation or production scheduling. This enables the provision of a set of complementary products integrated within a unique ecosystem.

“The system provides highly secured and traceable manufacturing and programming data management. Thanks to various mechanisms and user guidance, almaCAM ensures data protection and the successful completion of programming tasks. As an open system, it can easily interact with any existing manufacturing company’s information system, in particular ERP. Workshop management tools and production statistics are available in the system,” confirmed the manufacturer.

“Within the almaCAM environment, almaCAM Cut/Punch supports a wide range of cutting machines and punch presses as well as technology requirements at every step of programming. Providing nesting algorithms that fit various cutting needs, almaCAM significantly increases material yield while improving the manufacturing process on many other levels,” concluded ALMA.
