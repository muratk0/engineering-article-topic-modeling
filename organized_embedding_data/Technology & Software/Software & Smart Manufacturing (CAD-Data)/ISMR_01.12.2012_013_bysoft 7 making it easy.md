# BySoft 7 – making it easy

[TARİH: 01.12.2012 ISMR]

The last, but by no means least, innovation at EuroBLECH was the BySoft 7. “Not simply an update, but rather a completely new software generation,” as Bystronic explained. The software includes numerous new functions. If a user wishes to construct a part or a component, a single click opens the latest version of SolidWorks and a 3D and 2D CAD package.

At the CAM level, BySoft 7 users will find numerous innovations. Inside contours of cut parts, for example, can be automatically reduced. This function minimises the probability of the nozzle colliding with scrap pieces. Greater process reliability is also offered by what is known as spread nesting where nested parts can be better distributed. The BySoft 7 increases the distance between parts to achieve even higher process reliability. If the user wishes to go in the opposite direction he can now make use of a new function, compressed nesting. With compressed nesting, BySoft 7 minimises the safety distance to nest even more parts on metal sheet. Other features include optimised common cut, pre-piercing of selected contours, automatic scanning etc.

BySoft 7 consists of four modules: Sheet Processing, Tube Processing, Bending and Plant Manager. The Plant Manager plans and monitors all laser and waterjet cutting processes for the customer. It makes available all relevant machine and production data to ensure maximum transparency in sheet and tube processing.
