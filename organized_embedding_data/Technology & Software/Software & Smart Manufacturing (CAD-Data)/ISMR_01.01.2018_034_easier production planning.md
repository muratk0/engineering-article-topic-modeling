# Easier production planning

[TARİH: 01.01.2018 ISMR]

THE SCHRÖDER GROUP, a leading manufacturer of sheetmetalworking machines, has introduced new software for programming unfolding and bending sequences. Adapted to the machines, SCHRÖDER Unfold simplifies and improves production planning for users of MAK 4 Evolution UD, SPB Evolution UD, PowerBend Industrial UD and PowerBend Professional industrial folders.

"The SCHRÖDER Unfold software is able to import construction data as a Step-file (.STEP, .STP). An unfold assistant starts, enabling users to select material type and material thickness, machine type and available tools. The file then can be exported as a DXF-file for exact cuttings or as a .xml-file for direct export into the machine software POS 3000. Using 3D-graphics, the unfold assistant requires no previous operator knowledge or experience in CAD applications. The flat pattern can be designed using the bending calculations from Schröder folding machines," said the manufacturer.

User interface of the SCHRÖDER Unfold software

The software has a bending radius management system and an interactive measurement of component part. It automatically supports swaging and welded-on pieces. The software used on standard Windows PCs calculates the bending program and the necessary cycle times for better production planning. See www.schroedergroup.eu/en ■
