# Enhanced factory software functionality

[TARİH: 01.10.2024 ISMR]

JETCAM has announced the release of its CrossTrack version 5.7 software which includes over 140 new features, enhancements and fixes. The CrossTrack suite provides an end-to end shop floor interface, tracking material, orders, nests and kits.

“While many features enhance and extend existing functionality for composite and sheetmetal users, this release also includes two new modules to deliver full line automation for sheet metal manufacturers," commented the software specialist.

Key features include significant optimisation and reduction of SQL database size equating to a potential reduction of over 70% of the database size, said JETCAM. This, it added, will “improve overall performance, especially over slower networks."

The software also offers greater support for sheet metal users, with new line automation options available that can control the loading, cutting, unloading and sorting of parts.

“Legacy NC files can now be scheduled alongside JETCAM-generated nests, allowing users to standardise on a single schedule for both legacy and new nests. Connectivity has also been enhanced, with new web services and alerts so that CrossTrack can exchange manufacturing data with virtually any ERP, MES or hardware system," added JETCAM.

CrossTrack now allows a single material type to be associated with multiple 'material technologies', such as laser cutting with different gases. Users can now use the material stock code as the barcode, enabling companies to receive material directly from suppliers with barcodes that can be immediately scanned and recognised across the shop floor.
