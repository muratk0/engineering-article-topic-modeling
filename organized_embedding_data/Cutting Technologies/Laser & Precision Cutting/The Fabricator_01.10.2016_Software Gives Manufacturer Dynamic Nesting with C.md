# Software Gives Manufacturer Dynamic Nesting with Common Cutting on Lasers, Punches

[TARİH: 01.10.2016 The Fabricator]

Applications

SITUATION

Conyers, Ga.-based Hillphoenix Inc. manufactures commercial refrigeration and grocery display units. The company employs a variety of CNC punch and laser machines across two sites, with The Aquila Group’s DMM software passing orders for nesting to Hillphoenix’s CAM software.

The company’s software system could not common-cut on punching machines automatically, and its inferior tool management created programs that either needed manual interaction or were unable to run altogether. The software also had no teach mode, and material efficiency was poor.

"There were quality issues," said Michael McNeill, fabrication programmer. "We often use far more tools than can fit in the turret, so we’re constantly changing tools. With the old software, if two parts required multiple tools, it’d nest the parts but would not tool certain areas if the specific tool didn’t fit in the turret. Operators had to pay close attention to make sure that holes weren’t missing.

"Another issue was that parts carried a full turret layout of tools with them, regardless of what was used, and sometimes this would cause a tooling conflict," McNeill explained.

Hillphoenix investigated updates to its existing software, along with three other packages. One requirement was that any system would need to integrate with the Aquila DMM system, which feeds a list of required components for nesting and needs to be updated when nests and generated NC code are available. Another requirement was additional functionality to assist with managing the turrets automatically and double-hit detection.

RESOLUTION

The company selected Jetcam Expert CAD/CAM and nesting software, which can common-cut on both punch and laser machines. In addition, Jetcam is a partner with Aquila, so there are no issues integrating with DMM, and parts can be nested within parts.

During the implementation, Hillphoenix had more than 30,000 parts for its lasers that needed to be migrated. The company provided NestOne, Jetcam’s U.S. distributor, with a DXF file of each component, and these were automatically imported, tooled, and returned to Hillphoenix, ready for nesting. Punched components were processed internally at a later date using Jetcam’s built-in single component automatic processing, with the software able to process entire folders of parts automatically.

Five licenses of the software were installed with free-form and high-performance nesting modules. Some licenses included the RCP (remote control processing) module, and these were connected to Aquila DMM to provide automatic nesting. The others allowed staff to create new parts manually and create tooling layouts for optimum part quality. A sixth license was purchased later.

The tool teach feature is very helpful, according to McNeill. "We have a lot of geometries repeated across multiple part families, but until Jetcam we hadn’t found any product that would tool them the way we want it done. The ability to teach once and automatically have it applied to any matching geometry has greatly sped up programming and made programming of complex or unusual parts much easier. With our old software we’d have to manually tool each one every time."

Punch nests often are 10 percent more efficient with the new software. "We now have the ability to define what side we want to common-cut and how many parts to group, which has worked out really well for us. In fact, this has allowed us to use common cutting on parts that we previously thought were unsuitable. Our previous system would sometimes punch out the tabs holding parts in, but we now have the ability to limit groups of common-cut parts, which greatly assists with sheet stability."

The company estimates that weekly scrap savings resulting from the new software will provide a return on investment of eight months.
