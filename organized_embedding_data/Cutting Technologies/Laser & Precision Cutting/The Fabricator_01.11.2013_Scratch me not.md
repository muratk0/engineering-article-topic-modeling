# Scratch me not

[TARİH: 01.11.2013 The Fabricator]

Technology Spotlight

Laser/punch system’s turret does its job and gets out of the way

By Tim Heston, Senior Editor

No matter how fast they become, cutting lasers still can’t form embosses, louvers, offsets, or anything else. An incredibly fast laser may make the cutting department more productive, but eliminating an entire operation, like forming or tapping, may have an even more dramatic effect on overall shop productivity.

The die emerges from a retractable turret beneath the brush table to perform a punching operation.

Historically, this is where the modern laser/punch combo machine—the Swiss army knife of metal fabrication tools—has really made its mark. But all that really doesn’t matter if workpiece scratches force rework like polishing, or worse, a scrapped part.

Table designs have evolved to suit. Dirty roller ball tables can scratch sensitive material easily, so more fabricators in recent years have moved to brush tables. But as Tim Brady, product manager at Buena Park, Calif.-based Amada America, explained, even these don’t eliminate scratching potential entirely, particularly when using form tools.

“For certain forming tools, the dies stick up higher than the passline of the material,” he said. “So the material is dragged over these dies, which can cause some serious scratching.”

This problem led to a feature that’s on the company’s ACIES 2515T laser/ punch combination system. Introduced to North America this year, the all-electric system has a retractable die mechanism in the lower turret, which allows the lower turret to reside beneath the brush table. When a tool is selected, a small window in the brush table opens up, almost like a stage trapdoor, through which comes the die. The die performs its operation, then descends back below the table, with the trapdoor closing behind it.

To avoid marring or scratching parts, the system has a retractable turret below the brush table.

“So when you’re forming, you bring the tool up to perform the operation, then drop it out of the way rapidly before moving the material to the next forming position,” Brady said. “Then you bring it up again to perform your next form. This means when the material is being transported, it’s not being dragged over the die.”

This also simplifies tool placement. Traditionally, programmers have positioned forming tools away from punching tools on the turret. “If you have a punch next to a forming tool, you can distort the material during punching, because you have this big forming die nearby,” Brady said, adding that the retractable turret eliminates this problem. “Now you can have a punching tool next to a forming tool in an inner or outer station. You’re no longer limited when it comes to tool placement.”

The machine has a cabinet that can store up to 300 punches and up to two dies for each punch to accommodate different die clearances.

The combination machine has automatic tool change and, perhaps most significant, a tooling identification system. The machine has a cabinet that can store up to 300 punches and up to two dies for each punch to accommodate different die clearances. That adds up to 600 different punch and die combinations.

The system works with legacy tooling, but it also can work with the company’s new tools that have a QR code etched onto the side. This allows the machine to identify the tool automatically. (When loading older tools, the operator keys in the tool identification into the controller.) Because the machine “knows” what tools it has, it immediately flags the technician when it can’t find the correct tool (per the part program) in the cabinet.

The machine also knows how many hits a certain tool has performed, as well as how many times the tool has been sharpened. This means it can alert the technician when the tool needs to be changed out. It also recognizes when a die is slightly shorter, because of prior sharpenings, and adjusts the height of the die space in the lower turret to suit. This means an operator no longer needs to resort to shimming to maintain a consistent die height.

The turrets themselves have four built-in tapping stations. The auto-index function rotates and drives the tap into the workpiece. The stations can accept cutting as well as roll forming taps, depending on application requirements. The cutting taps cut threads, while the roll forming taps create threads via forming, displacing the metal to create the thread shape.

All this, Brady said, buttresses what the laser/punch combo is designed to do: operate continuously throughout a shift in a high-product-mix situation.

Here’s how it works. The software determines the optimal tool layout for the jobs in queue. While the machine is running, technicians load tools into the cabinet. From here, a manipulator grasps the tool (identifying it via the QR code) and places it into a “buffer” turret on the back side of the machine.

Once the current punching operation finishes, another manipulator removes the previously used tools and replaces them with the ones staged in the buffer turret. According to Brady, the tool changeout takes between eight and nine seconds. This changeout can take place while the CO
