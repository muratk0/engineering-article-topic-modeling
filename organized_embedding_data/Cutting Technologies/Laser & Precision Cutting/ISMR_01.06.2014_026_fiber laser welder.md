# Fiber laser welder

[TARİH: 01.06.2014 ISMR]

MIYACHI EUROPE has launched the Miyachi ML-6950A high-power fiber laser welder with high-power continuous-wave welding technology. A more powerful version of Miyachi’s existing fiber laser welders, the ML-6950A applies continuous wave (CW) technology with an output power of up to 5kW.

“An optional two-time sharing feature improves productivity, while the long-lasting laser diode provides high reliability and reduces maintenance cost. With excellent laser oscillation efficiency, and lower energy use, the ML-6950A also contributes to environmentally-friendly manufacturing,” said Miyachi Europe.

Waveform control includes a fixed mode that features three-level waveforms, and a flex mode to provide more complex waveforms. The power monitor tracks laser energy and average power to detect abnormalities. Also standard is a beam-switch safety shutter. The device comes with built-in single or dual optical outputs. A special “fade-in/fade-out” feature avoids marks at the end of seam welding and provides a smooth finish, even for overlapping circumference seam welding sections.

## Nesting software upgrade

HYPERTHERM, a manufacturer of plasma, laser and waterjet cutting systems, has announced a major version upgrade to its ProNest® advanced CAD/CAM nesting software for automated cutting. ProNest 2015 now contains a number of improvements designed to make the software more efficient and easier to use.

Features include an automatic nesting process, IntelliChoice™, that makes advanced level nesting decisions based on the available parts in the part list, as well as tabs to quickly navigate between nests, insert new nests or re-order nests by clicking and dragging tabs to the desired location. It can also export nests directly to a DXF file without installing a special DXF Polyline set-up or changing machines. There are expanded keyboard shortcuts throughout the software navigation and more standard features are now available.

Hypertherm is also releasing major version upgrades to its TurboNest® intermediate-level nesting software and NestMaster™ entry-level nesting software. These updates contain a number of the new features found in ProNest 2015. Hypertherm’s new CAD/CAM nesting software continues to integrate advanced functionality with an easy-to-learn and use interface. Current subscribers can upgrade to the new versions at no additional charge and receive technical support.
