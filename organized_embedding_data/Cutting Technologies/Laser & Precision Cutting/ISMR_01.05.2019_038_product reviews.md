## Enhanced laser processing

Above: Prima Power Laserdyne's new FASTTRIM software shows an example drilling program. The new software enables users to easily model the part, define process paths, define feature locations and build part fixtures.

PRIMA POWER LASERDYNE has announced the release of its FASTTRIM CAD/CAM software for use with its multiaxis precision laser processing systems. The FASTTRIM all-in-one software enables users to model parts, define process paths, define feature locations and build part fixtures. It enables posting of a complete program for 2D and 3D laser welding, drilling and cutting applications.

"In partnership with CENIT AG, we have a complete machine and CAD/CAM solution to meet customer requirements for applications in the aerospace, automotive, general manufacturing and medical device industries.

FASTTRIM supports the LASERDYNE® 795, LASERDYNE®430 and LASERDYNE® 606D multi-axis precision laser processing systems. Users can take full advantage of the capabilities within these systems including welding (with and without wire feed), percussion drilling, hole trepanning and cutting using QCW and CW lasers," explained Prima Power Laserdyne.

With over a dozen FASTTRIM laser processing benefits, the manufacturer highlights four in particular:

Full part simulation with collision detection allows the programmer to eliminate potential issues before sending the program to the manufacturing floor.

Auto programming functions to automatically program the part based on geometry of the model.

Supports up to 6 axes simultaneously.

Provides the ability to modify tool paths through sheet offset, cutter offsets and axis translations.
