CNC for rolling machines

Touch Command EVO is the latest version of the CNC designed for rolling machines from MG srl. New computation algorithms allow the completely automated generation of bending programs for any kind of shape, and the new closed-loop system allows programs to be executed with accuracy and repeatability, the company states.

Using a fast plate test procedure, the user can obtain optimal results at the first bent part, says the manufacturer. Alternatively, the user can apply corrections to preloaded plate libraries or modify the elaboration parameters at the time of program generation.

When multiple arc shapes are bent, the interpolation speeds are selected automatically and controlled with accuracy in any condition of stress and temperature. If the side roll starts to deviate from the right position during the interpolation, the rotation speed increases or decreases to help ensure correct bending.

The new CNC’s enhanced CAD system allows the user to draw and visualize shapes on the control or to load them in DXF format from a USB key. It also is possible to have a second desktop or laptop with the application for the program generation, allowing the user to work far from the machine and upload the programs on the CNC. After the selected shape has been loaded, the user chooses the kind of material, and the CNC automatically generates the program to bend it.
