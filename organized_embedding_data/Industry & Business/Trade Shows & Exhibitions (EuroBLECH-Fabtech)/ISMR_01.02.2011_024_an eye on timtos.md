# AN EYE ON TIMTOS

[TARİH: 01.02.2011 ISMR]

ISMR previews TIMTOS, the 2011 Taipei International Machine Tool Show, due to take place from 1-6 March 2011 in Taiwan.

TIMTOS (the 2011 Taipei International Machine Tool Show), organised by the Taiwan External Trade Development Council (TAITRA) and Taiwan Association of Machinery Industry (TAMI), will be held from 1-6 March 2011 at the Nangang Exhibition Hall in Taipei, Taiwan.

In 2009, TIMTOS attracted 895 exhibitors using 4871 booths, and welcomed 42,949 visitors to the show (4240 were from overseas). TIMTOS 2011 has, to date, 919 exhibitors and a record-breaking 5138 booths (90000 sq. m. show space). The organisers are expecting more than 5000 overseas visitors this year and around 47,000 domestic visitors.

## TAIWAN IN FOCUS

“Taiwan is the worlds’ fourth largest machine tool exporter, next to Germany, Japan and Italy,” said David Chuang, Vice Chairman of TAMI’s Machine Tool Committee. The overall export value reached US$ 1.9 billion. Taiwan is also the sixth largest machine tool manufacturer with an output value of US$ 2.4 billion.

“The total export value of Taiwan’s machine tool industry from January to August 2010 reached US$ 1.8 billion, a 62.9 per cent growth on the same period in 2009. The export value of forming machine tools hit US$ 4.1 billion, a 49.8 per cent increase compared to the same period in 2009.”

The 2009 Taiwan survey of machine tools showed that production value will go down with business recession on the export and home market. The production value in 2009 was NT$74.9 billion, a decrease of 50.6 per cent from the same period in 2008. The value of CNC machine tool production value in the same period of 2009 accounted for 72 per cent of the total production value, or NT$53.9 billion, a decrease of 50 per cent compared with the same period in 2008.

Export and Import statistics announced by Customs indicate that the value of machine tool exports during 2009 was NT$57.5 billion, a decrease of 50.7 per cent compared with 2008. The value for machine tool imports was NT$11.2 billion, a decrease of 76.7 per cent compared with 2008.

The 2010 Taiwan Survey of machine tools showed that production value would increase with business conditions on the export and home market. The production value in year-to-Sep. 2010 was NT$85.7 billion, an increase of 57.7 per cent from the same period in 2009. Meanwhile, production value for CNC machine tools grew 50 per cent to NT$64.3 billion.

Export and import statistics announced by the Ministry of Finance indicated that the value of machine tool exports during last year up to September was NT$66.8 billion, an increase of 57.7 per cent compared with the same period in 2009. The value for machine tools imports was NT$16.1 billion, an increase of 99.6 per cent compared with the same period in 2009.
