# A MACHINE TOOL INTERFACE STANDARD

[TARİH: 01.09.2019 ISMR]

By Annedore Bose-Munde

ISMR SAYS:

“A new umati showcase will be on display at EMO Hannover from 16-21 September 2019”

Since 2017, when the idea for umati was first introduced, work has continued steadily on developing it as a machine tool interface standard for the international machine tool industry. Visitors to EMO Hannover this September will be able to obtain the latest developments on this standard, now that key technical data has been included.

In this article, three experts explain exactly which umati developments visitors can expect to see at EMO Hannover.

Götz Görisch, who starts below, is responsible at the VDW (the German Machine-Tool Builders' Association) for digitisation and Industry 4.0, and is Chairman of the umati Joint Working Group.
